### V015-06 · 名字框换边 [CODE]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 PRS-6 里的"名字框换边" |
| 所属模块 | 对话的 Unity 侧程序集（现有的对话框视图） |
| 状态所有者 | 名字框在左还是在右，归对话框视图 |
| 规模 / 纯洁度 | 小 / A |
| 前置 | 无 |

**内容**
1. 对话框视图加一个入口：把名字框放到左侧或右侧。立即生效，没有动画。
2. 左侧的位置就是 Prefab 里保存的位置（含用户调过的值），视图在初始化时记下。
3. 右侧的位置是左侧的镜像，以对话框的竖直中线为轴：左侧时名字框的左边离对话框左边多远，右侧时名字框的右边就离对话框右边多远；上下位置不变。不另设字段。
4. 名字框的宽度随名字变。在右侧时向左展开，右边不动。
5. 默认在左。一段对话开始时回到左。
6. 名字为空时照旧不显示，与放在哪一侧无关。
7. 不新增节点：用的是 Prefab 里已有的名字框节点。

**验收（逻辑与数据）**：单测，办法与对话框视图现有的 53 项相同——默认在左；切到右侧后的位置是左侧的镜像；切回左侧后与初始化时记下的值一致；先切到右再改名字，右边的位置不变；名字为空时不显示；原 53 项不改并通过。名字很长时在右侧的实际排版交人工。回归门见 2.7。

### 2.3 立绘怎么摆（Schema 共同约定 A 的实现口径）

| 项 | 口径 |
|---|---|
| 显示锚点 | 屏幕上的一个点，相对屏幕底边中点，2560×1440 基准下的像素，向右、向上为正 |
| 对准点 | 立绘图上对到显示锚点的那个点：横向 = 0.5 + 偏移 x，纵向 = 偏移 y，都是相对图片的比例（0 到 1）。比例相对整张图片，含透明留白 |
| 大小 | 缩放为 1 时，图片的 1 个像素等于基准分辨率的 1 个像素 |
| 缩放 | 站位的缩放 × 角色表的缩放 × 本段的缩放。留空按 1 |
| 顺序 | 先对准，后缩放。缩放、说话者的放大与位移，都以显示锚点为中心 |
| 下半身 | 不裁切。靠纵向偏移把下半身放到屏幕底边以下 |
| 在哪一侧 | 显示锚点的横向位置大于 0 是右，小于 0 是左，等于 0 是中 |

有三处是对 Schema 的补充，不算与它冲突（用户 11-21 已确认，回写见 7.3）：约定 A 写"角色表的缩放与对话表的缩放相乘"，工程里的站位表另有一个缩放字段，这里三者相乘；默认站位的"出场人数"只算有立绘的人；显示锚点在屏幕中线右边的立绘默认水平镜像。
