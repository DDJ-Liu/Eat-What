**节点从哪来（与 V015-12 逐项一致）**

| 节点 | 来源 | 说明 |
|---|---|---|
| 立绘层 | 对话界面 Prefab 里已有，铺满屏幕 | 舞台组件挂在它上面 |
| 立绘模板 | **保存在 Prefab 里**，是立绘层的子节点，默认不激活。舞台按引用绑定 | 一个图片节点：不拦截点击；锚在父节点的底边中点；没有别的组件 |
| 每个人的立绘 | **运行时从模板复制**，放在立绘层下 | 一段对话结束退出后销毁。不保存进 Prefab |

舞台没有绑到模板时，什么都不显示，记一次诊断，对话照常进行。

**一张立绘怎么摆**（数值都来自 V015-01 的结果）

| 节点上的量 | 取值 |
|---|---|
| 锚点 | 父节点的底边中点 |
| 轴心 | 对准点（横向 0.5 + 偏移 x，纵向偏移 y） |
| 位置 | 显示锚点，加上入退场的滑动量，加上高亮的上浮与横移 |
| 尺寸 | 图片自己的宽高，按像素（缩放为 1 时图片 1 个像素等于基准分辨率 1 个像素） |
| 缩放 | 总缩放 × 高亮的放大。镜像开着并且在右侧时，横向取负 |
| 颜色 | 红绿蓝三个分量都等于高亮的亮度；透明度等于入退场的淡入淡出量 |
| 前后 | 按次序排，数字大的在前；高亮模型说"置前"的那一张排到最前，说完回到原来的位置 |

轴心放在对准点上，缩放与高亮的放大就都是以显示锚点为中心的。

**舞台能做的事**

| 能力 | 说明 |
|---|---|
| 显示一批 | 给一份 V015-01 的结果与各人的立绘图：为结果里的每个人复制一个节点，摆到入场的起点或终点 |
| 设置这一批的入场进度（0 到 1） | 0：左侧的在显示锚点左边 `portraitSlide` 处，右侧的在右边同样远处，中间的不偏；`portraitFade` 为真时透明度为 0。1：都在显示锚点上，不透明。中间按线性。`portraitFade` 为假时全程不透明 |
| 设置这一批的退场进度（0 到 1） | 0：当时的位置。1：向各自外侧移出退场的 `portraitSlide`，透明度 0。中间的立绘只淡出。这一批到 1 之后销毁 |
| 告知说话者 | 把"现在说话的是谁"交给 V015-02 的模型 |
| 每帧 | 把时间交给模型，把模型的五个量画到节点上。时间由外部传入 |
| 同时有两批 | 上一段的一批在退出、下一段的一批在进入时，两批各走各的，互不影响 |
| 清空 | 立即销毁全部节点，不播动画 |

**两个可调项**（都在舞台组件上，不进演出配置）

| 项 | 说明 |
|---|---|
| 镜像右侧立绘 | 开关，**默认开**（用户 2026-11-21）。开着时，显示锚点在屏幕中线右边的立绘水平翻转；左边和中间的不翻。关掉后都不翻 |
| 立绘取景的临时值 | 按角色 id 存偏移 x、偏移 y、缩放三个值。某个角色有临时值时，用它替换角色表里的三项：正在显示的立即变，之后再显示时也用它。提供设置、读取、清除三个入口。**只在编辑器与开发构建里存在**；不写回表、不存档 |

**与 0.1.4 的关系**：只新增一个组件，不改已有的界面层、压暗件、对话框视图。

**验收（逻辑与数据）**：单测，办法与 0.1.4 对话框视图的离线测试相同 `[核]`，立绘图用给定宽高的夹具——节点的轴心、位置、尺寸、缩放与 V015-01 的结果逐项一致；入场进度 0、0.5、1 时左、中、右三种立绘的位置与透明度；`portraitFade` 为假；退场进度 1 之后节点被销毁；模型的五个量画到节点上的结果；置前与复位后的前后顺序；两批互不影响；清空；镜像默认是开的，开与关各一次，左、中、右三种位置各自翻不翻；临时值的设置、立即生效、清除；发布构建的编译条件下临时值的代码不存在；没有绑模板时不显示、有诊断、不报错。立绘实际画出来的样子（图对不对、有没有变形、明暗与大小是否合适）交人工。回归门见 2.7。

### 2.3 立绘怎么摆（Schema 共同约定 A 的实现口径）

| 项 | 口径 |
|---|---|
| 显示锚点 | 屏幕上的一个点，相对屏幕底边中点，2560×1440 基准下的像素，向右、向上为正 |
| 对准点 | 立绘图上对到显示锚点的那个点：横向 = 0.5 + 偏移 x，纵向 = 偏移 y，都是相对图片的比例（0 到 1）。比例相对整张图片，含透明留白 |
| 大小 | 缩放为 1 时，图片的 1 个像素等于基准分辨率的 1 个像素 |
| 缩放 | 站位的缩放 × 角色表的缩放 × 本段的缩放。留空按 1 |
| 顺序 | 先对准，后缩放。缩放、说话者的放大与位移，都以显示锚点为中心 |
| 下半身 | 不裁切。靠纵向偏移把下半身放到屏幕底边以下 |
| 在哪一侧 | 显示锚点的横向位置大于 0 是右，小于 0 是左，等于 0 是中 |

有三处是对 Schema 的补充，不算与它冲突（用户 11-21 已确认，回写见 7.3）：约定 A 写"角色表的缩放与对话表的缩放相乘"，工程里的站位表另有一个缩放字段，这里三者相乘；默认站位的"出场人数"只算有立绘的人；显示锚点在屏幕中线右边的立绘默认水平镜像。

### 2.4 画面的层次

不变。立绘放在对话界面 Prefab 里已有的立绘层，在压暗层之上、对话框之下。

### 2.5 状态机的事实（V015-04、05 按它来写）

出场名单、说话者、场景反应这几个请求，在状态机里没有等待完成的回报口。收到就开始做，不回报。出字不等立绘，立绘的渐变也不等出字。入场、退场仍然按 0.1.4 的约定，等那一次调用返回之后再回报。
