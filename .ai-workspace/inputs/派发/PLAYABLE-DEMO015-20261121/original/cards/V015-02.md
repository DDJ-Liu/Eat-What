### V015-02 · 说话者高亮模型 [CODE]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 PRS-7 的规则部分 |
| 所属模块 | 对话的纯逻辑程序集 |
| 状态所有者 | 每张立绘此刻的亮度、放大、上浮、横移、是否置前 |
| 规模 / 纯洁度 | 小 / A |
| 前置 | 无 |

**输入**：一段对话里要显示的立绘（角色 id、在哪一侧）；快照里说话者分组的六项——`listenerDim`、`speakerScale`、`speakerRise`、`speakerShiftInward`、`transition`、`transitionTime`；"现在说话的是谁"；每帧传入的时间。

**每张立绘的三种目标**

| 目标 | 亮度 | 放大 | 上浮 | 横移 | 置前 |
|---|---|---|---|---|---|
| 未分明暗（一段刚开始、第一句之前） | 1 | 1 | 0 | 0 | 否 |
| 说话者 | 1 | `speakerScale` | `speakerRise` | 左侧的向右 `speakerShiftInward`，右侧的向左同样的量，中间的 0 | 是 |
| 不说话 | `listenerDim` | 1 | 0 | 0 | 否 |

**规则**

| 情形 | 结果 |
|---|---|
| 说话者是名单里某个要显示的人 | 他是"说话者"，其余都是"不说话" |
| 说话者不在名单里（含旁白） | 全部"不说话" |
| 说话者没有立绘（不在 V015-01 的结果里） | 与不在名单相同：全部"不说话" |
| 同一个角色在名单里出现两次 | 两张都按说话者 |
| 连续两句是同一个人 | 不变，不重新过渡 |
| `transition` 为渐变 | 亮度、放大、上浮、横移四个量，各自从当前值线性走到目标值，用时 `transitionTime` |
| 渐变途中又换了说话者 | 从当前值接着走向新的目标，不跳变，重新计 `transitionTime` |
| `transition` 为瞬切，或 `transitionTime` 为 0 | 立即到目标值 |
| 置前 | 在切换的那一刻立即生效，不过渡 |

模型只管这五个量。放大以什么为中心、亮度怎么画出来，归舞台（V015-04）。时间由外部传入，不读全局时钟。

**验收（逻辑与数据）**：单测——三种目标的数值；左、中、右三种位置的横移方向；说话者不在名单时全部变暗；说话者没有立绘；连续同一个人不重新过渡；渐变在一半时间时四个量各走到一半；渐变途中换人不跳变；瞬切；时长为 0；置前立即切换。回归门见 2.7。

### 2.3 立绘怎么摆（Schema 共同约定 A 的实现口径）

| 项 | 口径 |
|---|---|
| 显示锚点 | 屏幕上的一个点，相对屏幕底边中点，2560×1440 基准下的像素，向右、向上为正 |
| 对准点 | 立绘图上对到显示锚点的那个点：横向 = 0.5 + 偏移 x，纵向 = 偏移 y，都是相对图片的比例（0 到 1）。比例相对整张图片，含透明留白 |
| 大小 | 缩放为 1 时，图片的 1 个像素等于基准分辨率的 1 个像素 |
| 缩放 | 站位的缩放 × 角色表的缩放 × 本段的缩放。留空按 1 |
| 顺序 | 先对准，后缩放。缩放、说话者的放大与位移，都以显示锚点为中心 |
| 下半身 | 不裁切。靠纵向偏移把下半身放到屏幕底边以下 |
| 在哪一侧 | 显示锚点的横向位置大于 0 是右，小于 0 是左，等于 0 是中 |

有三处是对 Schema 的补充，不算与它冲突（用户 11-21 已确认，回写见 7.3）：约定 A 写"角色表的缩放与对话表的缩放相乘"，工程里的站位表另有一个缩放字段，这里三者相乘；默认站位的"出场人数"只算有立绘的人；显示锚点在屏幕中线右边的立绘默认水平镜像。

### 2.4 画面的层次
