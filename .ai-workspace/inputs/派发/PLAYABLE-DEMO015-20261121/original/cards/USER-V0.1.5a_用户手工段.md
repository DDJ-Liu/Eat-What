### 用户手工段（V015-14 之后）

| 做什么 | 说明 |
|---|---|
| 看一眼立绘的归属 | 番茄、土豆各用自己的图；章鱼给了主角；石榴的第一张给了对话专用角色（人四），第二张没有接。想换，在工作簿的角色表里改立绘一格，按配置说明导表 |
| 调每张立绘的大小与位置 | 进游戏，和对应的 NPC 交谈，按 F8 打开立绘调参，用加减按钮调到合适，点"复制"，把三个值抄回工作簿的角色表，导表。**调参区里的值是临时的，退出游戏就没了** |
| 调站位 | 演出配置资产里的站位表：每个站位的位置、缩放、次序。改完下一段对话生效 |
| 看右侧立绘的镜像合不合适 | 默认是镜像的。不合适，在对话界面 Prefab 的立绘层上把开关关掉 |
| 挪第五个占位锚点 | 放到你想让"人五"站的位置 |
| 可选：调说话者的强调 | 演出配置资产里说话者分组的六项 |
