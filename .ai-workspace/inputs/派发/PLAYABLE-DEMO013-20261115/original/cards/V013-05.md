### V013-05 · 场景状态的加载应用 [CODE]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 SCN-3 |
| 所属模块 | LongLoop |
| 状态所有者 | 每个 NPC 在不在场、在哪个锚点、朝向、形象、气泡池 |
| 规模 / 纯洁度 | 中 / A |
| 前置 | V013-02、V013-03、V013-04 |

**步骤对照**

| 步 | 内容 | 与前一步的关系 | 实现位置 | 状态所有者 |
|---|---|---|---|---|
| 1 | 用当前场景的文件名在场景表里找到场景 id；找不到则报告并结束 | — | 应用器 | 无 |
| 2 | 取该场景的默认状态（本版不读存档） | 第 1 步完成后 | 应用器 | 无 |
| 3 | 取这个状态的全部条目；物件与出口条目跳过并记诊断 | 第 2 步完成后 | 应用器 | 无 |
| 4 | 对每个角色条目：先在目标索引里找同 id 的预摆实例；没有就用通用 NPC Prefab 生成一个，并给它角色标记 | 第 3 步完成后，逐条进行 | 应用器 | 生成出的对象归应用器管理 |
| 5 | 在场与否：条目写不在场，就把它停用，后面几步不做 | 第 4 步完成后 | 应用器写，壳执行 | 应用器 |
| 6 | 位置：条目填了锚点就放到锚点上；留空则保持原位。留空而又是新生成的，停用它并记诊断 | 第 5 步完成后 | 应用器 | 应用器 |
| 7 | 朝向：条目填了就设置 | 与第 6 步同时 | 应用器写，壳执行 | 应用器 |
| 8 | 形象：角色表里填了形象 Prefab 就换上；没填则保持实例自身的 | 与第 6 步同时 | 应用器写，壳执行 | 应用器 |
| 9 | 气泡池：条目填了就写入触发组件；没填则保持实例自身的 | 与第 6 步同时 | 应用器写 | 应用器 |

**内容**
1. 应用器是场景里的一个组件，场景加载、目标索引收集完成之后运行一次。
2. 对外提供"按指定的状态 id 重新应用一次"的入口，供调试入口使用：先把上一次由它生成的 NPC 清掉，再从第 3 步重新走。不演出，直接到位；不写存档。
3. 场景里有预摆实例而状态里没有它的条目：不碰它，保持场景里摆的样子。
4. 形象 Prefab 的引用来自导表时的绑定（V013-10）。引用为空而角色表里填了名字的，用占位形象并记诊断。

**不做**：状态切换的演出、对话未结束时的延后、跨场景、存档、物件与出口。

**验收（逻辑与数据）**：单测，用假的索引、假的壳——九步各自的结果；预摆实例被复用而不重复生成；锚点留空时预摆实例不动、新生成的被停用；不在场的条目；形象与气泡池的三行取值顺序；状态里没有条目的预摆实例不被改动；重新应用时上一次生成的被清掉、预摆的恢复到应用前的样子；物件与出口条目被跳过。回归门见 2.5。

## 二、结构与硬约束

### 2.1 代码放哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 气泡的取句与触发规则 | 对话的纯逻辑程序集 | 不引用引擎 |
| 气泡视图、运行时接入点 | 对话的 Unity 侧程序集 | 不引用 LongLoop |
| 演出目标索引、通用 NPC 的壳、场景状态应用、气泡的触发组件、调试入口 | LongLoop | LongLoop 新增对两个对话程序集的引用 |

对话系统不引用 LongLoop。需要街道提供的能力（主角的地面位置、角色头顶的挂点）通过接口传入。

### 2.2 状态的唯一所有者

| 状态 | 所有者 |
|---|---|
| 场景里有哪些角色、锚点 | 演出目标索引（V013-02） |
| 每个 NPC 在不在场、在哪个锚点、朝向、用哪个形象、挂哪个气泡池 | 场景状态应用器（V013-05）。它写入，别人不写 |
| NPC 自身的位置、朝向、当前形象子对象 | NPC 的壳（V013-03） |
| 每个 NPC 的气泡冷却、当前池里播到哪一段哪一句 | 气泡的触发组件，逻辑在 V013-06 |
| 屏幕上的每个气泡 | 气泡视图（V013-07） |

### 2.3 取值顺序（Schema v2.5.1 共同约定 B，本版只涉及形象与气泡池）

| 配表里的值 | 实例自身的值 | 结果 |
|---|---|---|
| 填了 | 任意 | 用配表的 |
| 留空，或没有这个角色的条目 | 有 | 用实例自身的 |
| 留空 | 没有 | 没有（无形象 / 不冒气泡） |

"实例自身的形象"指实例的形象挂载点下已经存在的子对象；"实例自身的气泡池"指触发组件上保存的池 id。

### 2.4 禁止

对话的纯逻辑程序集里出现引擎类型；对话系统引用 LongLoop 或短循环；修改 0.1.2 镜头代码的行为、主角控制器与主角形象组件；修改 T1~T15 的定义与数据；往正式表里写占位内容以外的行；为了通过而修改既有测试的断言；新写探针、守卫、比较器；使用已冻结的验证探针。

发现本包与 Schema v2.5.1 或现行代码冲突，停驻上报。
