### V013-07 · 气泡视图 [CODE]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 TRG-4 的表现部分 |
| 所属模块 | 视图在对话的 Unity 侧程序集；触发组件在 LongLoop |
| 状态所有者 | 屏幕上的每个气泡归视图；触发组件只持有池 id 和逻辑状态 |
| 规模 / 纯洁度 | 中 / B |
| 前置 | V013-03、V013-06 |

**内容**
1. 触发组件挂在通用 NPC 的壳上：保存实例自身的气泡池 id（可留空）；每帧把主角的地面距离交给 V013-06 的逻辑；触发时向视图请求显示。
2. 说话者是别的角色时，用目标索引找到那个角色的头顶挂点；找不到就跳过这一句并记诊断。
3. 视图：在指定的头顶挂点上方显示一个气泡，内容是文本 key 对应的本地化文本。出现时淡入；存活到时间后上漂并淡出；同一个 NPC 冒新气泡时，旧的立即走消失动画。不同 NPC 的气泡互不影响，数量不限。
4. 气泡跟随头顶挂点移动。气泡的大小不随纵深缩放变化；绘制在角色之上，不被街景物件遮挡。
5. 存活时间、淡入时间、上漂距离、淡出时间取自演出配置的分级分组。
6. 气泡的底图：按 1.4 的核对结论，复用现有的或做程序占位。
7. 冒气泡不锁操作，不影响镜头。

**验收（逻辑与数据）**：单测——触发组件把距离与触发结果正确转给逻辑与视图；说话者找不到时跳过；同一 NPC 的新气泡替换旧气泡；气泡的生命周期各阶段的时长取自配置。表现本身不在这里验。回归门见 2.5。

## 二、结构与硬约束

### 2.1 代码放哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 气泡的取句与触发规则 | 对话的纯逻辑程序集 | 不引用引擎 |
| 气泡视图、运行时接入点 | 对话的 Unity 侧程序集 | 不引用 LongLoop |
| 演出目标索引、通用 NPC 的壳、场景状态应用、气泡的触发组件、调试入口 | LongLoop | LongLoop 新增对两个对话程序集的引用 |

对话系统不引用 LongLoop。需要街道提供的能力（主角的地面位置、角色头顶的挂点）通过接口传入。

### 2.2 状态的唯一所有者

| 状态 | 所有者 |
|---|---|
| 场景里有哪些角色、锚点 | 演出目标索引（V013-02） |
| 每个 NPC 在不在场、在哪个锚点、朝向、用哪个形象、挂哪个气泡池 | 场景状态应用器（V013-05）。它写入，别人不写 |
| NPC 自身的位置、朝向、当前形象子对象 | NPC 的壳（V013-03） |
| 每个 NPC 的气泡冷却、当前池里播到哪一段哪一句 | 气泡的触发组件，逻辑在 V013-06 |
| 屏幕上的每个气泡 | 气泡视图（V013-07） |

### 2.3 取值顺序（Schema v2.5.1 共同约定 B，本版只涉及形象与气泡池）

| 配表里的值 | 实例自身的值 | 结果 |
|---|---|---|
| 填了 | 任意 | 用配表的 |
| 留空，或没有这个角色的条目 | 有 | 用实例自身的 |
| 留空 | 没有 | 没有（无形象 / 不冒气泡） |

"实例自身的形象"指实例的形象挂载点下已经存在的子对象；"实例自身的气泡池"指触发组件上保存的池 id。

### 2.4 禁止

对话的纯逻辑程序集里出现引擎类型；对话系统引用 LongLoop 或短循环；修改 0.1.2 镜头代码的行为、主角控制器与主角形象组件；修改 T1~T15 的定义与数据；往正式表里写占位内容以外的行；为了通过而修改既有测试的断言；新写探针、守卫、比较器；使用已冻结的验证探针。

发现本包与 Schema v2.5.1 或现行代码冲突，停驻上报。
