### V013-02 · 演出目标索引 [CODE]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 SCN-1 |
| 所属模块 | LongLoop |
| 状态所有者 | 本场景的角色与锚点清单 |
| 规模 / 纯洁度 | 小 / A |
| 前置 | V013-01 |

**内容**
1. 两个标记组件：角色标记（带角色 id，可带 `#2` 一类的多实例后缀）、锚点标记（带锚点 id）。物件标记本版不做。
2. 注册表：场景加载后收集本场景里的全部标记；标记启用、停用时同步增减。
3. 查找：按角色 id（含后缀）取对象；按锚点 id 取位置；`player` 取主角。找不到时返回"没有"并给出诊断，不抛异常。
4. 同一个 id 出现两次时，保留先登记的，给出诊断。

**验收（逻辑与数据）**：单测——登记与注销；按 id 查找角色与锚点；多实例后缀互不混淆；重复 id；找不到；`player`。回归门见 2.5。

## 二、结构与硬约束

### 2.1 代码放哪

| 内容 | 位置 | 说明 |
|---|---|---|
| 气泡的取句与触发规则 | 对话的纯逻辑程序集 | 不引用引擎 |
| 气泡视图、运行时接入点 | 对话的 Unity 侧程序集 | 不引用 LongLoop |
| 演出目标索引、通用 NPC 的壳、场景状态应用、气泡的触发组件、调试入口 | LongLoop | LongLoop 新增对两个对话程序集的引用 |

对话系统不引用 LongLoop。需要街道提供的能力（主角的地面位置、角色头顶的挂点）通过接口传入。

### 2.2 状态的唯一所有者

| 状态 | 所有者 |
|---|---|
| 场景里有哪些角色、锚点 | 演出目标索引（V013-02） |
| 每个 NPC 在不在场、在哪个锚点、朝向、用哪个形象、挂哪个气泡池 | 场景状态应用器（V013-05）。它写入，别人不写 |
| NPC 自身的位置、朝向、当前形象子对象 | NPC 的壳（V013-03） |
| 每个 NPC 的气泡冷却、当前池里播到哪一段哪一句 | 气泡的触发组件，逻辑在 V013-06 |
| 屏幕上的每个气泡 | 气泡视图（V013-07） |

### 2.3 取值顺序（Schema v2.5.1 共同约定 B，本版只涉及形象与气泡池）

| 配表里的值 | 实例自身的值 | 结果 |
|---|---|---|
| 填了 | 任意 | 用配表的 |
| 留空，或没有这个角色的条目 | 有 | 用实例自身的 |
| 留空 | 没有 | 没有（无形象 / 不冒气泡） |

"实例自身的形象"指实例的形象挂载点下已经存在的子对象；"实例自身的气泡池"指触发组件上保存的池 id。

### 2.4 禁止

对话的纯逻辑程序集里出现引擎类型；对话系统引用 LongLoop 或短循环；修改 0.1.2 镜头代码的行为、主角控制器与主角形象组件；修改 T1~T15 的定义与数据；往正式表里写占位内容以外的行；为了通过而修改既有测试的断言；新写探针、守卫、比较器；使用已冻结的验证探针。

发现本包与 Schema v2.5.1 或现行代码冲突，停驻上报。
