### V012-02 · 视角浮动函数 [CODE]

| 项 | 内容 |
|---|---|
| 所属模块 | 流水线 `[核]` |
| 状态所有者 | 浮动过渡状态是纯数据，由驱动持有 |
| 规模 / 纯洁度 | 小 / A |
| 前置 | 无 |

**内容**
1. 输入：视线轴向量（已有的输入抽象给出 `[核]`，鼠标相对画面中心的归一化位置，两轴各在 −1 到 1 之间）、开关、边缘判定区比例、响应曲线、进入时长、退出时长、门控标志、本帧时长、上一帧状态。输出：两轴各自的浮动量，归一化到 −1 到 1。
2. 判定区：从画面边缘向内，占可见范围的给定比例。预设 0.25，即归一化位置的绝对值超过 0.5 才开始浮动。两轴分别判定。
3. 响应：进入判定区越深，浮动量越大，且增长越来越快（预设二次曲线）；到画面边缘为满量。
4. 过渡：浮动量朝目标值变化，增大用进入时长，减小用退出时长。
5. 门控为真或开关关闭：目标值为 0，已有的浮动量按退出时长回落，不硬切。
6. 本卡只出归一化的量。乘多大的距离、如何与其他偏移求和，由 V012-04 负责。

**验收**

| 段 | 内容 |
|---|---|
| 逻辑与数据 | 单测：鼠标在画面中央时两轴为 0；刚进判定区时接近 0，到边缘时为满量；判定区内越靠边增长越快；保持在边缘，经过进入时长后达到满量；移回中央，经过退出时长后回到 0；门控置位后按退出时长回落到 0；开关关闭同上；横向进入判定区不影响纵向的值；左右、上下对称 |
| 引擎内 | 无 |
| 人工 | 无（随 V012-05 一起看） |

**交付**：参数调整说明补视角浮动一段。
