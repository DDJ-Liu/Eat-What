### V012-03 · 纵向输入偏移函数 [CODE]

| 项 | 内容 |
|---|---|
| 所属模块 | 流水线 `[核]` |
| 状态所有者 | 纵向输入偏移的过渡状态是纯数据，由驱动持有 |
| 规模 / 纯洁度 | 小 / A |
| 前置 | 无 |

**内容**
1. 输入：纵向输入（上、下、无）、脚底的实际纵向速度、纵向速度阈值、进入时长、退出时长、曲线、本帧时长、上一帧状态。输出：归一化到 −1 到 1 的偏移量，方向与输入方向一致。
2. 触发条件：有纵向输入，并且实际纵向速度的绝对值低于阈值。也就是顶着可行走区域的边还在按。
3. 触发时朝输入方向按进入时长建立；输入停止或速度恢复后按退出时长回落。
4. 正常纵向走动（速度高于阈值）不触发。

**验收**

| 段 | 内容 |
|---|---|
| 逻辑与数据 | 单测：有输入且速度低于阈值，经过进入时长后达到满量；松开后经过退出时长回到 0；速度恢复到阈值以上后回落；没有输入时为 0；速度高于阈值时即使有输入也不触发；按上与按下方向相反；输入从上直接换成下时连续过渡 |
| 引擎内 | 无 |
| 人工 | 无（随 V012-05 一起看） |

**交付**：参数调整说明补纵向输入偏移一段。
