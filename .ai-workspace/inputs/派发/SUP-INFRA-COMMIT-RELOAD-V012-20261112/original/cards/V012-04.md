### V012-04 · 流水线合成：顺序、视野比例、两轴求和 [CODE]

| 项 | 内容 |
|---|---|
| 所属模块 | 流水线 `[核]` |
| 状态所有者 | 不新增状态 |
| 规模 / 纯洁度 | 中 / A |
| 前置 | V012-01、V012-02、V012-03 |

**内容**
1. 每帧的计算顺序按第二节的对照表：先算视野与比例，再走已有的目标点与前视，再并入浮动与纵向输入偏移，最后求和与安全区裁剪。
2. 视野比例作用于：前视距离、横向上限、纵向上限、浮动量、纵向输入偏移量。**不作用于**：FOCUS、任何速度类参数、死区与安全区（它们本来就按可见范围的比例）。
3. 横向：已有的前视（规则不动）加上浮动 X。浮动 X 的满量取横向上限。两者相加，裁到"横向上限 × 比例"。
4. 纵向：纵向输入偏移加上浮动 Y。两者的满量都取纵向上限。相加后裁到"纵向上限 × 比例"。
5. 死区与安全区用本帧 Size 对应的可见范围计算。
6. 第 3、4 条里"满量取该轴上限"是设计文档没有写明的地方，这里先按这个做，见第七节。

**验收**

| 段 | 内容 |
|---|---|
| 逻辑与数据 | 单测：前视配 5、最大 Size 10，Size 为 10 时目标领先 5，Size 为 5 时领先 2.5；Size 连续变化时目标连续无跳变；横向上限同比例缩小；向右走同时鼠标在右边缘，总偏移不超过"横向上限 × 比例"；向右走同时鼠标在左边缘，两者相抵；纵向输入偏移与浮动 Y 之和不超过"纵向上限 × 比例"；FOCUS 在任何 Size 下不变；门控时浮动贡献为 0 而前视不受影响。**回归**：动态视野关闭、鼠标居中、不顶边界时，输出与改动前逐值相同；现有三组单测一条不改、全部通过 |
| 引擎内 | 无 |
| 人工 | 无（随 V012-05 一起看） |

**交付**：参数调整说明里写明"偏移类参数的数值是最大视野时的距离"，并列出哪些参数乘比例、哪些不乘。

## 二、合成顺序对照表（硬约束，每张卡都适用）

在 E2 附录 D 的基础上，写入本版的落点与 0.1.1 已有的实现事实。

| 步 | 内容 | 实现位置 | 状态所有者 |
|---|---|---|---|
| 0 | **本帧视野与比例**：由移动状态算出本帧 Size；比例 = Size ÷ 最大 Size；动态视野关闭时比例为 1 | 流水线的动态视野函数（V012-01） | 视野状态，由驱动持有，纯数据 |
| 1 | 跟随点 = 脚底 + FOCUS。**FOCUS 不乘比例** | 流水线（已有） | 无 |
| 2 | 死区推动出目标点；回中只作用于目标点。死区按本帧可见范围算 | 流水线（已有） | 目标点、回中状态（已有） |
| 3 | 横向：前视（主角基准，触边锁存）＋ 浮动 X；前视距离与横向上限都乘比例；求和后裁到上限 | 流水线（已有前视；V012-02、V012-04） | 前视权重与锁存（已有）；浮动过渡状态 |
| 4 | 纵向：纵向输入偏移 ＋ 浮动 Y；偏移与纵向上限都乘比例；求和后裁到上限 | 流水线（V012-02、V012-03、V012-04） | 各自的过渡状态 |
| 5 | 门控时浮动归零；全部偏移求和后做一次安全区裁剪 | 流水线（已有裁剪；V012-04） | 无 |
| 写出 | 目标点写到镜头目标节点；Size 写到本帧镜头状态 | 驱动（已有写目标；V012-05 加写 Size） | — |
| 6 | 阻尼，唯一一次 | Cinemachine 的 Composer；停步倍率由 Binder 临时换算（已有，不动） | Cinemachine；临时换算值归 Binder |
| 8 | 边界钳制，随 Size 变化 | Cinemachine 的 Confiner2D（V012-05 核对） | Cinemachine |
| 视差 | 读**边界钳制之后**的相机位置，给各层容器加补正 | 视差组件（V012-06） | 各层容器的补正量归视差组件 |

**禁止**：流水线读取相机位置；驱动写相机的原始位置或位置修正量、调用强制定位（瞬移重置除外）、用反射改 Cinemachine 内部；在第 6 步之外管理相机的速度或位置；给任何通道单独再加一层阻尼（通道自己的进出过渡不算）；改动 Binder 的停步倍率逻辑；修改用户保存的参数值。

发现本表与 E2 或现行代码冲突，停驻上报，不自建替代方案。
