### V012-01 · 动态视野函数 [CODE]

| 项 | 内容 |
|---|---|
| 所属模块 | 流水线（纯函数库）`[核]` |
| 状态所有者 | 视野状态是纯数据，由驱动持有（本卡只定义结构） |
| 规模 / 纯洁度 | 小 / A（单车道、单模块、不碰场景） |
| 前置 | 无 |

**内容**
1. 输入：开关、最小 Size、最大 Size、是否在移动、放大时长与曲线、缩回时长与曲线、是否冻结、本帧时长、上一帧的视野状态。输出：本帧 Size、比例（Size ÷ 最大 Size）、新的视野状态。
2. 规则：初始为最小 Size；移动时按放大的时长与曲线渐变到最大；停下后按缩回的时长与曲线渐变回最小。
3. 中途起停：从当前 Size 出发，不跳变。实现方式由开发端定。
4. "是否在移动"沿用现有的移动判定（脚底实际位移速度与移动速度阈值比较），纯纵向走动达到阈值也算移动 `[核]`。
5. 最小等于最大：Size 恒定，比例为 1。
6. 开关关闭：不产出 Size（驱动据此不写镜头），比例为 1。
7. 冻结：冻结期间 Size 保持不变；解冻后从冻结值继续，不从最小值重来。
8. 最大 Size 不是正数、最小大于最大、时长为负：拒绝为无效配置，不自动改值（沿用现有的无效配置处理方式）。

**验收**

| 段 | 内容 |
|---|---|
| 逻辑与数据 | 单测：从最小开始移动，经过放大时长后到达最大；从最大停下，经过缩回时长后回到最小；放大途中停下、缩回途中起步，Size 连续无跳变；最小等于最大时恒定且比例为 1；关闭时不产出 Size 且比例为 1；冻结期间不变、解冻后从冻结值继续；30 / 60 / 120 帧率下到达时间一致；无效配置被拒绝 |
| 引擎内 | 无 |
| 人工 | 无（随 V012-05 一起看） |

**交付**：参数调整说明里补动态视野一段（开关、上下限、两个时长与曲线各自在哪调、调大调小的效果）。

### 1.3 必须原样保留的现有行为（0.1.1 已验收）

| 行为 | 来源 |
|---|---|

## 二、合成顺序对照表（硬约束，每张卡都适用）

| 0 | **本帧视野与比例**：由移动状态算出本帧 Size；比例 = Size ÷ 最大 Size；动态视野关闭时比例为 1 | 流水线的动态视野函数（V012-01） | 视野状态，由驱动持有，纯数据 |
