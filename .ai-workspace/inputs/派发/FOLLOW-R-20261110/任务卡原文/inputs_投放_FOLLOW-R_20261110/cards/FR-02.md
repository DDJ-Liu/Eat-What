### FR-02 · Driver 接入与旧模型删除 [CODE] `M · 80` `module: L`
**dependsOn**：FR-01。
**目标**：一个 `StreetFollowDriver : CinemachineExtension` 取代 `FollowRecenterExtension` + `StreetFollowChannels`；相机位置只由 Cinemachine 管。
**内容**：
1. Driver 在 `PrePipelineMutateCameraStateCallback`：读主角脚底/速度/`IGameInput`/门控 → 调 `StreetFollowPipeline` → 把目标点写入 `CameraTarget` 节点（场景根下独立对象，非主角子节点）；透传 Size；把各步结果送 `StreetCameraDebug`（目标点、前瞻权重、回中阶段、裁剪前后偏移）。
2. `CameraFollowConfigBinder` 精简为一次性同步：Composer `Damping = dampingX/Y × 4.605`（沿用 `ToCmDamping`）、Dead Zone 关、Lookahead 关、ScreenPosition 0、TargetOffset 0；配置变更事件触发重同步；**删除**阻尼租借、外部改动检测、Suspend/Restore。
3. **删除**：`FollowRecenterExtension.cs`、`FollowRecenterMath.cs` 中的 `FollowMotion` / `Track` / `TrackAdditive` / `Return` / `ReturnVertical` / `LookaheadBase` / `MoveGoal`（`ToCmDamping`、`Finite`、`IsTeleport` 迁入 Pipeline 或 Toolkit）、`StreetFollowChannels.cs`、`ChannelPipeline.cs`（逻辑已迁）、反射代码。`StreetFollowPoint` 保留（①）。不留旧实现开关、不留注释掉的旧代码。
4. 既有单测：F-01/F-02 的旧用例随实现删除；PRB 探针中引用旧类型的断言改指 Driver 的调试输出。
**白名单**：`Assets/Scripts/LongLoop/` 下上述文件；对应测试；`docs/参数调整说明_街道镜头.md`（C.3 段改写：E2 参数 ↔ 流水线 / Composer.Damping）。
**验收**：编译 0 Error；全仓 grep 无 `ForceCameraPosition`（瞬移重置处除外）、无 `RawPosition =`、无 `PositionCorrection`、无 `BindingFlags.NonPublic` 指向 Cinemachine；离线 SDK 编译通过；单测全绿。
