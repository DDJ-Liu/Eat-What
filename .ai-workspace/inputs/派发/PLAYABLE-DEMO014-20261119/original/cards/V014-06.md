### V014-06 · 对话框视图 [CODE]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 PRS-2、PRS-3 的显示部分 |
| 所属模块 | 对话的 Unity 侧程序集 |
| 状态所有者 | 对话框、名字框、两个按钮的显示状态 |
| 规模 / 纯洁度 | 中 / B |
| 前置 | V014-02、V014-05 |

**内容**
1. 对话框：一块底板加文字区。文字是本地化读取之后的最终文字。
2. 出字：一句开始时，**先把整句排好版，换行位置定下来，再按打字机模型给的可见字数逐字显示**。已经显示的字不因为后面的字出现而移动位置。
3. 名字框：贴在对话框左上角外侧。显示的名字由状态机给出 `[核]`（句上的改名优先，否则是角色名）；名字为空时整个名字框不显示。**本版固定在左侧**。
4. 两个按钮：AUTO、快进（>>>）。各是一个切换态，点一下开、再点一下关，开与关看得出区别。开关的所有者是推进输入模型，按钮只负责转达和显示。按钮上的字就是"AUTO"和">>>"，不走本地化。
5. 推进输入：点击画面（两个按钮的范围除外），或者按交互键，都算一次"推进"，交给对话服务。点在按钮上不算推进。
6. 点击与按键怎么取：经 Toolkit 的输入抽象，不直接调引擎的输入接口。界面按钮的点击沿用工程里现有可点击界面的做法 `[核]`；确实没有屏幕空间按钮的先例时，用界面事件系统，并在报告里写明。
7. 显示与收起的动画由 V014-07、08 驱动。本卡提供按进度设置的两种方式：滑上（位移加淡入）；缩放弹出（从 82% 到 100% 加淡入）。
8. 占位外观：底板、名字框、按钮都用程序画的纯色块加文字，做法同气泡，不等美术。
9. 初始布局见下表。这些不是 D5 附录 C 的参数，放在视图组件自己的可调字段上，并写进参数说明。

**初始占位布局**（2560×1440 基准。取自行为参考稿，按 4/3 换算；D5 附录 B 写明这些值待界面规格文档重定）

| 对象 | 初始值 |
|---|---|
| 对话框 | 宽 2107、高 333；水平居中；底边距屏幕底 54 |
| 文字区 | 字号 59、行距 83；距对话框左边 93、右边 107、上边 70 |
| 名字框 | 高 83；宽随名字，最小 267；字号 43；左边距对话框左边 67；上沿高出对话框上沿 45 |
| AUTO 按钮、快进按钮 | 各宽 133、高 53；底边距对话框底 30；中心分别距对话框右边 440、267 |
| 滑上的距离 | 取快照的 `boxSlideDistance`，不在这里 |

**验收（逻辑与数据）**：单测——名字为空时名字框不显示、非空时显示、句上改名优先；可见字数增加时，已显示的字的位置不变（用排版后的行信息判断）；点按钮只改对应的开关、不产生推进；点击画面与按交互键各产生一次推进；两种弹出方式在进度 0 和 1 时的状态。表现交人工。回归门见 2.7。

### 2.3 取值顺序（Schema v2.5.2 共同约定 B，本版新增对话与标记两项）

| 条目里的值 | 实例自身的值 | 结果 |
|---|---|---|
| 填了 | 任意 | 用条目的 |
| 留空，或没有这个角色的条目 | 填了 | 用实例自身的 |
| 留空 | 留空 | 对话：不能交谈。标记：按实际绑定的对话推导——普通级显示「…」，剧情级显示金色「！」，没有对话则不显示 |

标记的取值 `none` 是一个明确的值，意思是"不显示"，不等于留空。

### 2.5 状态机的回报约定（V014-07、08、09 都要遵守）

状态机向视图发出一个请求的那次调用里，视图不能直接回头调状态机。即使是立刻就完成的事——时长为 0、步骤被去掉、本版不支持的请求——也要等这次调用返回之后再回报。回报时带上状态机当时给的那个关联对象，过期的不报 `[核]`。

### 2.6 禁止

对话的纯逻辑程序集里出现引擎类型；对话系统引用 LongLoop 或短循环；改状态机、调度器、推进输入模型、取值器的既有行为；除 V014-11 写明的那一处外改镜头代码的行为；除 V014-10 写明的那一处外改主角控制器；改主角的形象组件；改气泡的显示逻辑；往演出配置里加参数，或改用户已保存的参数值；修改 T1~T23 的定义；往正式表里写本包列明之外的行；为了通过而修改既有测试的断言（V014-11 写明的夹具调整除外）；新写探针、守卫、比较器；使用已冻结的验证探针。

发现本包与 Schema v2.5.2 或现行代码冲突，停驻上报。
