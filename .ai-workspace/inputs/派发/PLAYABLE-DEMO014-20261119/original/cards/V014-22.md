### V014-22 · 版级冒烟 [ENGINE · 验收类]

| 项 | 内容 |
|---|---|
| 对应 | 追踪表 SUP-3 |
| 规模 / 纯洁度 | 小 / B |
| 前置 | V014-19、用户手工段完成 |
| 轮次 | 验收类，累计最多 3 轮；满 3 轮转人工，不申请追加 |

**内容**：一次运行，不注入任何输入，不开始对话。

**验收（引擎内，三条）**
1. 街景能加载；运行时接入点报告可用；对话服务、对话界面实例、操作锁、游戏状态组件、交互选择器在场，相互之间的引用不为空；对话服务报告"没有对话在进行"。
2. 运行约十秒，控制台没有新增报错。
3. 数据到位，**按 id 点名，不比总数**。默认状态下，这五个对象解析出的实际绑定对话与标记分别是：

| 对象 | 实际绑定的对话 | 标记 |
|---|---|---|
| `chr_test_talker` | `dlg_test_talk_a` | 「…」 |
| `chr_test_passer_a#2` | `dlg_test_talk_b` | 不显示 |
| `chr_test_potato` | `dlg_test_talk_c` | 「…」 |
| `chr_test_tomato` | 没有 | 不显示 |
| `chr_test_passer_a` | 没有 | 不显示 |

只核这五个。用户另外摆进场景的 NPC 不计入，不因此判失败。用户在手工段里改过这五个对象的占位内容时，以用户保存的为准：第 3 条改为只核"五个对象都能解析出结果、没有诊断报错"，并在报告里写明。

无论通过还是满 3 轮，都交付定稿的人工检查说明。

## 引擎卡的通用约束

- 每一步在前一步完成后才开始；任何一步失败，停在那一步并报告，不跳过。
- 操作轮与验收轮分开计数：操作没完成的轮次算操作轮，按分模式额度，超出向用户申请；操作完成之后为检查而跑的算验收轮，累计最多 3 轮，满 3 轮转人工，不申请追加。
- 引擎内断言只限三类：加载与接线存在；运行中没有新增报错；数据已经到位。不判行为时序、数值阈值、表现效果。
- 数据到位的断言按 id 点名，不比总数；用户自己加进场景或表里的内容不计入。
- 不移动、不重设父级任何已有物件；不修改用户保存的参数值与配置资产里的现值；不使用已冻结的验证探针；不新写探针、守卫、比较器。
- 场景与资产的保存按现行的保存协议；保存前备份。
- 发现本卡与 Schema v2.5.2 或现行工程冲突，停驻上报。

### 2.3 取值顺序（Schema v2.5.2 共同约定 B，本版新增对话与标记两项）

| 条目里的值 | 实例自身的值 | 结果 |
|---|---|---|
| 填了 | 任意 | 用条目的 |
| 留空，或没有这个角色的条目 | 填了 | 用实例自身的 |
| 留空 | 留空 | 对话：不能交谈。标记：按实际绑定的对话推导——普通级显示「…」，剧情级显示金色「！」，没有对话则不显示 |

标记的取值 `none` 是一个明确的值，意思是"不显示"，不等于留空。
