## GOV-04 [CODE·DevTools] · 上下文量监测与 chat 重载预警　`complexity: M`　轮次预算 80
**目的：** 让每张卡结束时都能看到线程上下文处在什么量级，到阈值只提示你，**不做任何自动重载**。
**改动清单：**
| 文件 | 处置 | 要点 |
|---|---|---|
| `DevTools/Workflow/Get-ThreadContext.ps1` | 新建 | 返回当前线程最近一次响应的 `inputTokens`（provider 记录可得时取真值；不可得时用 `read_thread` 元数据或累计 fresh 字节估算，并标 `source: provider|estimated`） |
| `.ai-workspace/queue.ps1` | 修改 | `Claim` 与 `Complete` 各记一次 `contextTokens / contextSource` 到 usage jsonl；`Complete` 回执附 `contextWarning: NONE | ADVISE | STRONG` |
| `.ai-workspace/supervised.ps1`（控制台心跳） | 修改 | 每次心跳顺带记控制台自身线程的上下文量与一次 `get_usage_limits` 到同一 jsonl（字段 `role: console`），让控制台也进计量；不改心跳频率 |
| `templates/TASK_COMPLETION_REPORT.md` | 修改 | 六要素之后固定一行：`上下文：<量级>（<来源>）/ 阈值 ADVISE 150K · STRONG 200K / 建议：无 ｜ 本卡后可重载 ｜ 建议收束后重载` |
| WATCH（`watch.ps1`） | 修改 | 新事件 `CONTEXT_HIGH`（≥STRONG）进收件箱；事件包只含线程 id、量级、来源 |
| `workers/CODE.md` / `ENGINE_MCP.md` / `DATA.md`、`CORE.md` | 修改 | 两句话：到 ADVISE 不中断；到 STRONG 完成当前卡后在报告提示；**重载只由用户执行** |
| `DevTools/Workflow/Get-UsageReport.ps1` | 修改 | 周报增两列：各车道（含 console）线程上下文量分布；STRONG 触发次数 |
| `DevTools/Workflow/Test-ContextWarning.ps1` | 新建 | 夹具：三档各触发一次、报告行渲染、WATCH 事件入箱、**静态断言：代码中不存在任何自动新建线程 / Yield / 重载的调用路径** |
**阈值初值：** ADVISE 150K、STRONG 200K；两周后按实测分布调。
**验收：** 夹具通过；一次真实任务回执含 `contextWarning`；控制台一次心跳记录含 `role: console` 的上下文与用量字段；allowed-list `git diff --check` 0。不进独立 Final。

## GOV-05 [CODE·DevTools + 控制台] · 任务卡复杂度分级与轮次预算　`complexity: S`　轮次预算 40
**目的：** 评价口径从"单任务绝对消耗"改为"分级预算 + 空转比例"。
**规则（写入 CORE / CONTROL_CHAT 拆解规则）：**
| 级 | 判定（满足任一条即升级） | 轮次预算 |
|---|---|---|
| S | 改动 ≤3 文件；不写场景/Prefab/资产；无 Play/Build；认领条目 ≤2 | 40 |
| M | 改动 4～10 文件，或写 1 个场景/Prefab，或需 Play 回归，或条目 3～5 | 80 |
| L | 改动 >10 文件，或多场景/Prefab，或需 Build，或条目 >5，或新建工具 | 120（软限内；超出走 GOV-02 交接） |
**改动清单：**
| 文件 | 处置 | 要点 |
|---|---|---|
| `.ai-workspace/queue.ps1` | 修改 | 任务卡字段 `complexity`（必填，S/M/L）与派生 `turnBudget`；`Complete` 时计算 `turnsActual / turnBudget`，并要求执行器在回执提供 `idleTurns`（验证重跑、读回确认、工具报错重试、同文件重复读 四类计数）；缺字段拒绝 Complete |
| `templates/TASK_COMPLETION_REPORT.md` | 修改 | 增固定一行：`轮次：实际 N / 预算 B（S|M|L）· 空转 K（x%）· 超预算原因：<必要|空转>` |
| `CORE.md`、`CONTROL_CHAT.md`、`workers/*.md` | 修改 | 分级判定表；超预算不触发停止，只要求报告说明；评价看级别与空转占比 |
| `DevTools/Workflow/Get-UsageReport.ps1` | 修改 | 周报按级别汇总：任务数、平均轮次/预算比、平均空转占比、超预算任务列表 |
| `DevTools/Workflow/Test-TaskTier.ps1` | 新建 | 夹具：缺 complexity 拒绝入队；三级预算映射；Complete 缺 idleTurns 拒绝；周报分组渲染 |
**验收：** 夹具通过；现存已派未领取的卡（GOV-01～03、DATA-F1、GOV-04）由控制台补 `complexity` 后仍可领取；allowed-list `git diff --check` 0。
