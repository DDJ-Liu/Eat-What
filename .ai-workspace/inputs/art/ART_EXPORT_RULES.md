# ART 必读导出与 PSD 分层规则

| ID | 规则 | 日报处理 |
|---|---|---|
| E1 | 正向导出，不内嵌旋转；旋转交引擎排布 | 宽高比变化只作警报，不凭像素比例断言素材已经旋转或已转正 |
| E2 | 结构件按可见像素紧裁，不留统一透明外边距 | alpha>0 包围盒；83%为当前批次诊断参照，不是要求美术补17%边距 |
| E3 | ui_shicai_/ui_caipin_/ui_tag_/ui_gongju_ 在512画布内保留作者相对比例，引擎不逐张裁可见区 | 画布非512报告；不自动裁剪、缩放原图 |
| E4 | 图标不内嵌描边，由引擎 SpriteOutline2D 生成；结构件描边逐件标注 | 内容判定交人工，不把文件级扫描冒称描边已通过 |
| E5 | 出画素材仍完整绘制，由引擎裁切 | 缺件/完整性需要人工视觉核实 |
| E6 | 2560×1440目标，总清单“2K目标像素”为实际占位，P1依据PSD真值 | >4096的画布警报来自本轮日报指令增补，不伪称原E6包含4096字样 |
| P1 | PSD一元件一组，组名为契约文件名或可辨中文，禁止元件混组 | PSD变更列人工分层核查 |
| P2 | MULTIPLY/LINEAR_DODGE光影层归所属元件组，组名标[光影] | 不仅凭PSD存在就判定合规 |
| P3 | 旧元素删除或归隐藏的“_旧版”组，不与新版同层级可见 | 仅报告，不擅自删除 |
| P4 | 文字图层或单标签分层，不合并为全标签像素层 | 留人工项 |
| P5 | PSD按16:9/2K整数倍画布，如5120×2880 | 仅已读取的尺寸才报数值；不读PSD分层不宣称通过 |
| P6 | 参考图附分层PSD，用于切件/位置表/总清单 | 记录交付缺口 |

日报额外阈值：可见宽高比 `abs(newRatio/oldRatio-1)*100 > 5%` 红；旧可见区没有可核查证据时写“不可比较”，不得使用旧画布比例代替。两个轴可见占比与83%相差超过10个百分点黄；任一画布边<8、纯透明、可见像素全部纯黑或PNG解码失败红；最大边>4096黄。红项只阻断消费该文件的部署，不把黄色/人工内容判断升级成全局熔断。
