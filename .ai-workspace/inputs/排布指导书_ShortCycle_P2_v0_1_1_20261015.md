> 定位：P2「逐步做菜」新场景（G63）的首版施工图。**归集稿**——内容全部来自 B1 v2.1.2 第四章、F2-a v0.6.2 第六章、Schema v2.4.1（T14 / §四 / §八）、G40/G41/G63/G74、指导书 v0.3.1 的尺度与所有权规则；不新增设计，只把已定结论翻成对象树、状态矩阵与坐标初值。设计空白处的决策点 D-P2-01~05 **用户 2026-10-15 全按推荐项裁决**，本版已固化（候选 G81~G85，总档 v1.5.4 入表）。

## 一、空间与机位

```
独立场景 ShortCycle_P2.unity（Additive 加载于 P1 交接后；G63 不接旧 CookingProcess）
单机位：Cam_P2 = (0, 0, -10)，正交 7.2，不平移（D-P2-02 取 A）
世界 x 可见范围 [-12.8, 12.8]，y [-7.2, 7.2]
```

| 槽 | 世界 x 范围 | 内容 |
|---|---|---|
| 顶条 | 全宽，y ∈ [5.6, 7.2] | ② 顶部信息条：食谱名 + 步骤进度（≤10 步，三态） |
| 主区 | 全宽，y ∈ [-3.6, 5.6] | S0：① 多分区总览（5 区横排）；S1：分区细节（居中放大，含洞洞板 + 操作台） |
| 底栏 | 全宽，y ∈ [-7.2, -3.6] | ③ 备菜区背包栏（P2 实例，绑定 `prep_zone_contents`）+ 「手」工具常驻位 + 冰箱补货入口（回 P1） |
| 左下 | (-11.6, -6.4) | ④ ESC |
| 右上 | (11.6, 6.4) | ⑤ 查看步骤（⑤ 步骤详情弹层，复用 P0/P1 同一内容绑定） |

与 P0P1 的关系：P2 不在连续空间内；P1→P2 为场景加载 + 画面跳变；P2→P1 补货为反向加载并**保持 P2 状态**（F2-a 6.10.1，M9-B6-R4）。

## 二、状态与显隐所有权矩阵（初版）

状态：`S0 总览` / `S1 分区内` / `S2a 常规弹窗` / `S2b 等待弹窗` / `Modal_StepDetail` / `Modal_ExitConfirm`（正交）/ `Transition_In`（从 P1 进入）/ `Transition_Out`（到 P3 或回 P1）。

| Set（*_Group） | S0 | S1 | S2a | S2b | 备注 |
|---|---|---|---|---|---|
| TopBar_Set | 显 | 显 | 显 | 显 | 常显；S1 增"返回总览"按钮 |
| Overview_Set（5 区卡位 + 锁定占位） | 显 | 隐 | 隐 | 隐 | 分区进入命中区覆盖整区 |
| AreaDetail_Set（**单实例**，按分区 ID 重绑） | 隐 | 显 | 显·保留视觉 | 显·保留视觉 | 洞洞板、设施、操作区、必备品气泡锚点 |
| PrepTray_Set（备菜区背包栏） | 显 | 显 | 显·禁交互 | 显·禁交互 | 层级 2 轻度高亮由它触发 |
| HandTool_Set | 隐 | 显 | 隐 | 隐 | 「手」常驻位 |
| InteractionModal_Set（S2a 壳） | 隐 | 隐 | 显 | 隐 | 压 Layer_Modal |
| MiniGameModal_Set（S2b 壳 = MG0 host） | 隐 | 隐 | 隐 | 显 | 压 Layer_Modal |
| StapleBubble_Set | 隐 | 条件 | 隐 | 隐 | 食材放入 + 承载物激活后 |
| ESC / StepDetail 按钮 | 显 | 显 | 隐 | 隐 | 弹窗期间不可退出（B1 4.4 不允许反悔） |
| RestockEntry_Set（冰箱补货） | 显 | 隐 | 隐 | 隐 | 点击 → 回 P1（保持状态） |

所有权规则沿用指导书 v0.3.1 §二：显隐只由 Director 按 viewTable 执行；Binder 只填内容；Set 的 `overflowRenderers` 仅登记出画件；本场景**不新增 Sorting Layer / Tag / Layer**。
