# 对话参数调整说明

最后核对：2026-11-20，依据当前演出配置资产、已保存的对话/提示 Prefab、街景引用和实际消费者源码。表内“当前保存值”是工程实际值，不是用户终调建议；未进行新的引擎运行或视觉签收。

2026-11-21 已按演出配置和通用 NPC Prefab 更新保存值。文字模板的源码初值在 C.7 中单列。

## 一、在哪里改，什么时候生效

主要资产：`Assets/Settings/Narrative/DialoguePresentationConfig.asset`，Inspector 展开 **Data** 后选择对应分组中的模板。各组都有唯一 `name=default`；自定义模板名区分大小写，应唯一，不删除或复制出第二个 default。

段落表的 `tier_profile`、`entrance_profile`、`exit_profile`、`text_profile` 等列选对应组的整套模板；空表示 default。最终优先级是 **default → 本段指定模板 → 本段有效 overrides**。模板是整组替换，不是只用非空字段拼default。缺失模板会给诊断并回default；default缺失/重复或配置非法会使解析失败，不能用覆盖值掩盖结构错误。

**对话演出参数在一段对话开始时取一次快照；对话途中改了，要到下一段才生效。** 同一段的后续句不会重抓整套演出配置；同一轮 next_dialogue 接到的新段会重新取值。想对比改动，应正常结束/中止旧段，再开始下一段，不在原句中途判断无效。

触发配置有独立入口：NPC 的 **Narrative Dialogue Trigger > Trigger Template** 选 trigger 组，空用default。交互选择和头顶标记会按其处理时机重新解析该组，因此半径/标记不是“当前对话段快照”的一部分，不承诺统一等到下一段才变化；修改模板后让配置正常通知/重新进入游戏再核。`Dialogues` 没有 trigger_profile 列，不能把段落 overrides 中可解析的 trigger 字段误当作街景独立驱动的调参入口。

气泡每次产生时冻结当次显示快照；已有泡不因资产改动立刻改寿命。冷却截止在成功触发时确定，之后改值/换池不缩短已产生的截止。独立提示的淡入/淡出/Pivot等在其运行资源创建时读取，改后停游戏再进入最明确。

### 单段覆盖示例

```text
entrance.boxMode=ScalePop;text.charsPerSecond=12;tier.normalDim=0.55
```

这是 Dialogues.overrides 的示例，不是已保存全局默认。字段写完整组名前缀，数字不带单位或百分号，枚举按原拼写；多项用英文分号。字符串含分号/等号时加双引号，中文标点集合例如 `text.punctuationSet="，。！？…,.!?"`。未知key/非法值会诊断并跳过该项；同key重复只用首项，不靠后项修正首项错误。详[配表说明](剧情八表配表说明.md)。

时间为秒，世界距离为Unity世界单位；界面距离为2560×1440参考像素，随Canvas按屏幕高度缩放。数字须有限；时间、速度、半径与倍率非负；RGBA与压暗量在0～1。零值的具体表现看下面消费者说明，不把“数据合法”误当“立刻完成”。

## 二、当前普通对话真正生效的参数

### Tier：压暗

| Inspector名 / 字段 | 当前保存值、单位 | 调大/调小与限制 |
| --- | --- | --- |
| Normal Dim / normalDim | 0.4，0～1 | 越大越暗，0不压暗，1黑色遮罩最强。多个有效压暗请求取最大值；本段撤销后还有其它请求时，不保证全亮 |

普通段通过入/退场使用此值。当前没有剧情级完整画面，不能从字段名推断已经接入剧情镜头/黑边。

### Trigger：交互与头顶标记

| Inspector名 / 字段 | 当前保存值、单位 | 调大/调小、零值及联动 |
| --- | --- | --- |
| Interact Radius / interactRadius | 2.1，地面世界距离 | 变大更远可交互；必须严格小于半径，等于边界不入选；0不入选。距离比较使用Foot，不是贴图中心；F8远距按钮专门绕过距离，不拿它验半径 |
| Marker Bob Amplitude / markerBobAmplitude | 0.1，世界单位 | 相对挂点上下各此幅度，总行程2倍；0不浮动，不随NPC纵深缩放倍乘 |
| Marker Bob Period / markerBobPeriod | 1.2，秒 | 越大越慢；0停在挂点，不除零、不无限快 |
| Marker Fade Back Time / markerFadeBackTime | 0.3，秒 | 对话结束后的淡回时间；越大越慢，0立即显示。对话开始仍立即隐藏，没有额外淡出参数 |
| Marker Talked Tint / markerTalkedTint | RGBA(0.5,0.5,0.5,1) | 只染已聊的Talk样式；RGB调颜色/亮度，A调透明度，0可不可见。与淡回alpha相乘；Story仍金色，不走此灰态 |

显式none隐藏；空标记按实际段等级推导。已聊颜色不禁止再次交谈。标记的时间走游戏delta；独立提示淡入出使用不缩放的UI时间，不要用两者节奏互相推断。

### Entrance：入场

| Inspector名 / 字段 | 当前保存值、单位 | 调整效果 |
| --- | --- | --- |
| Order / order | Sequential | Sequential先压暗再出框；Parallel同时开始。普通版不为没有立绘的步骤空等 |
| Dim Time / dimTime | 0.15秒 | 压暗到本段normalDim的时间；变大更慢，0直接到目标 |
| Box Mode / boxMode | SlideUp | SlideUp自下上移并淡入；ScalePop为固定小幅弹出缩放并淡入，两者共用boxTime |
| Box Time / boxTime | 0.2秒 | 框入场时长；0立即到位。改Slide距离不改变时长 |
| Box Slide Distance / boxSlideDistance | 187参考像素 | 只对SlideUp生效；越大起点越低，0只保透明度变化。ScalePop不读它，也没有单独的弹性/倍率字段 |

顺序模式当前压暗+出框合计0.35秒是按保存值推算，不是原生计时验收。ScalePop的起始比例与回弹形状在视图代码内固定，未成为可配置模板字段。

### Text：文字组全部八项

| Inspector名 / 字段 | 当前保存值、单位 | 调整效果与边界 |
| --- | --- | --- |
| Chars Per Second / charsPerSecond | 25，Unicode文本元素/秒 | 越大越快；组合字符/代理对不拆开，换行不吃显字时间。0会等待手动补全，**不是即时全显** |
| Punctuation Pause / punctuationPause | 0.07秒 | 指定标点后的额外停顿，越大越明显；0无额外停顿，末尾完成不再为最后标点空等 |
| Punctuation Set / punctuationSet | `，。！？～…、；：,.!?` | 这组字符触发标点停顿；空字符串不暂停。它是字符串，不是正则表达式 |
| Click While Typing / clickWhileTyping | CompleteLine | 普通显字中点一次：CompleteLine补全当前句；改SkipToNext会直接请求下一步，可能跳过未显示内容 |
| Click While Typing Fast / clickWhileTypingFast | SkipToNext | 快进开关打开时，显字中的点击策略，独立于上项；可改CompleteLine保当前句 |
| Auto Wait / autoWait | 1.2秒 | AUTO开时，从当前句完成起等待再请求下一步；越大停留越久，0在句完成后尽快请求，不是在显字开始就计时 |
| Fast Forward Multiplier / fastForwardMultiplier | 4倍 | 快进时乘显字速度并取消额外标点等待；0使自动显字不前进，仍可手动操作；不是整场游戏timeScale |
| Advance Cooldown / advanceCooldown | 0.3秒 | 两次手动推进意图的最短间隔；越大越防连点也越迟钝，0不设此间隔。开始同帧的输入仍有服务侧保护，不靠改此项取消 |

慢显时通常第一次点击补全、下一次点击才推进；要按当时的快进策略区分。AUTO/快进按钮只切换原模型，开关在同一服务存活期间跨句、跨续接及下一次交谈保持，新服务才重置，不写进已聊文件。

### Exit：退场

| Inspector名 / 字段 | 当前保存值、单位 | 调整效果 |
| --- | --- | --- |
| Order / order | Sequential | Sequential先收框再回亮，Parallel两者同时；没有立绘/镜头的普通段不额外空等 |
| Box Time / boxTime | 0.15秒 | 收框时长，使用入场Box Mode的反向姿态；越大越慢，0直接关闭 |
| Undim Time / undimTime | 0.2秒 | 撤销本段压暗请求后的回亮时长，越大越慢；0直接到剩余请求的最大目标，并非强制全亮 |
| Control Resume / controlResume | AfterBoxClosed | 收框完即可结束/恢复控制，回亮可继续；AfterCameraReturned在当前普通实现等收框与回亮全部完成，没有实际回镜头步骤 |

一段正常结束会记已聊并释放自己的操作锁；真正停用/中止清自身界面与请求，不把它记为正常完成。不要用极短时长掩盖接线或重复回调。

## 三、已有气泡与命令的边界

气泡仍消费Tier中的 Bubble Lifetime=2.5秒、Bubble Fade In Time=0.2秒、Bubble Exit Rise=80参考像素、Bubble Exit Fade=0.4秒，以及Trigger中的 Auto Bubble Radius=2.9世界单位、Auto Bubble Cooldown=10秒。改大分别更久/更慢/漂更远/范围更远/间隔更长；0按对应阶段无时长、无半径或无额外冷却处理。气泡不读交谈的interactRadius；见[气泡说明](../组件说明文档/视觉特效/剧情气泡配置与使用说明.md)。

Tier.Command Execution Mode当前Parallel，是底层命令调度的真实枚举；但普通演示内容没有命令，外部角色移动/场景切换等处理器未接全，调整它不会自动生成这些画面。需要动作先确认现支持能力，不把“能解析命令”当“已有画面执行”。

## 六、调整与核对示例

- 想让普通段更暗：只对测试段加 `tier.normalDim=0.55`，结束旧段后重开，别先改全项目default；再与0.4比较。
- 想看慢显和弹出：当前 `dlg_test_talk_b2` 已有 `entrance.boxMode=ScalePop;text.charsPerSecond=12`，与前段当前的 SlideUp / 每秒 25 个文本元素比较，不把它误写回全局default。
- 想提示离NPC远一些：调该NPC的Prompt Anchor世界位置；想玩家更远可触发才调interactRadius，二者不是同一件事。
- 想标记更高但气泡不动：只挪Marker Anchor；想标记浮动更大才调markerBobAmplitude，不能用浮动代替静态位置。

存档位置、F8实际按钮、只清已聊与发布包安全重置见[内容配置说明](街景NPC内容配置说明.md#四已聊记录与安全重置)。新美术、正式图片入口的限制见[缺失清单](街景NPC缺失内容清单.md)。配置变化和实际观感分别核，不能以无Error或导表通过代替用户检查。

## 覆盖语法、类型与诊断完整参考

当前已提供 `DialogueParameterRegistry.Entries/TryGet` 和 `DialogueOverrideParser.Parse`。注册表读取原69个参数字段上的单位声明及真实字段类型，不保存另一套默认值。这里的key格式为 **`组.字段`**，大小写敏感；它对应上表的实际字段。例如 `data.text[0].autoWait` 的参数key为 `text.autoWait`，数组元素的name由对应组profile或Trigger Template选择。

组前缀固定为 `tier`、`trigger`、`entrance`、`layout`、`speaker`、`expression`、`text`、`reaction`、`cg`、`exit`。每组上表中的69个参数全部注册，包括触发等全局用途参数；模板name是选模板的身份字段。`entrance.order` 与 `exit.order`、`entrance.boxTime` 与 `exit.boxTime` 分别独立。`tier.commandExecutionMode`控制同句命令方式，entrance/exit的order用于入退场步骤，虽然复用枚举，职责不同。

注册项提供 `Key`、`Group`、`FieldName`、`ValueType`、`Kind`、`Unit`。单位标记为s、u、px、ratio、×、chars/s、bool、string、template-key、RGBA、px/×/layer或none；none表示枚举无物理单位。px基准仍为2560×1440，RGBA每分量[0,1]，站位的复合单位分别对应位置/缩放/层号。字段的单位声明是注册来源，实际数值约束仍复用原字段校验。

覆盖集基本形式：

```text
text.charsPerSecond=24;tier.commandExecutionMode=Sequential;cg.kenBurnsPanX=-53;cg.kenBurnsPanY=20
```

key与赋值两侧可留空白；空/null/纯空白覆盖集表示无覆盖，末尾允许一个分号。中间空条目（如两个连续分号）、缺等号或空key会报告语法问题。CG横向和纵向各有独立key：`cg.kenBurnsPanX`、`cg.kenBurnsPanY`。

| 类型/Kind | 文本形式 | 解析结果与边界 |
| --- | --- | --- |
| 数值/Number | `1.25`、`1e-2`、`-53` | 实际Single，使用小数点，不随系统地区变化；有限性、非负/比例要求按对应原字段校验 |
| 布尔/Boolean | `true`、`false` | 实际Boolean，大小写不敏感；1/0或yes/no不是布尔值 |
| 枚举/Enum | `Parallel`、`ScalePop`等上表声明名 | 实际既有枚举类型，名称大小写精确；数值序号不作枚举文本 |
| 字符串/String | `hop`或`"hop"` | 裸文本去两端空白，引号内保留空白与分隔符；空值表示空字符串，不表示自动补default |
| 位置/Point | `(173,-173)` | 实际PresentationPoint，固定x、y顺序，允许有符号偏移 |
| 颜色/Color | `(0.5,0.5,0.5,1)` | 实际PresentationColor，固定r、g、b、a顺序，各分量[0,1] |
| 站位数组/Stations | 见下方 | 实际PortraitStationSet[]，包含人数、每个站位的ID/位置/缩放/层号 |

`cg.kenBurnsCurve`还接受Schema原拼写 `linear`、`quadratic`、`smooth_step`、`ease_in_out`，分别返回既有Linear、Quadratic、SmoothStep、EaseInOut。其余枚举按上表的实际名称，例如 `exit.continuationMode=Seamless`。

字符串含ASCII分号或双引号时，使用完整引号值：

```text
text.punctuationSet=";=，。！？";expression.expressionChangeTemplate="hop"
```

引号内支持 `\"`、`\\`、`\n`、`\r`、`\t` 五种转义，Unicode文字直接填写。未闭合引号、未知转义或引号后多余内容会报错。等号可作为字符串内容，分号只在引号外分隔赋值。

站位数组使用专用固定元组格式：

```text
layout.stations=[(2,[("left",-747,0,1,0),("right",747,0,1,0)])]
```

外层每项为 `(人数,[站位,...])`，站位为 `("id",x,y,scale,layer)`。ID必须加引号，也可用上述字符串转义；x/y为有符号px、scale非负、layer为有符号32位整数。人数为正整数、同组人数不重复，站位条数等于人数，单个人数集合中的ID非空且唯一。可写多个不同人数集合。`layout.stations=[]`沿用原字段校验的合法空集合语义；它只表示新解析值为空，未修改原default中的四套站位。该固定格式只编码现有站位结构，没有引入通用序列化格式。

例如：

```text
expression.symbolOffset=(173,-173);trigger.markerTalkedTint=(0.5,0.5,0.5,1)
```

位置、颜色和站位均以原复合参数整体返回，内部各分量保留实际类型和字段含义。解析只产出值，不进行图片偏移、镜头漂移、布局或颜色处理。

### 诊断和结果使用

结果有 `Success`、`Values` 和 `Diagnostics`；每个成功值含真实注册定义及 `Value`。数值/布尔/枚举是各自实际类型，位置和颜色为纯结构体，站位数组为新创建的纯数据对象。列表只读，复合内容仍是可变编辑数据，逐段取值器生成冻结快照。

任何条目失败时，整体 `Success=false` 且 `Values` 为空，避免部分应用。每条诊断给出 `Key`、`Problem`、UTF-16文本位置 `Position` 和具体 `Reason`：

| 输入示例 | 问题 |
| --- | --- |
| `text.unknown=1` | UnknownKey：参数集合没有该key |
| `text.autoWait=wrong` | InvalidValue：需要有限数值 |
| `text.autoWait=-1` | InvalidValue：原字段要求非负，值不会被钳制 |
| `text.autoWait=1;text.autoWait=2` | DuplicateKey：同一key重复，整组失败，不采用最后值 |
| `text.autoWait=wrong;text.autoWait=2` | 同时保留首个值错误与重复诊断，不让第二条掩盖首错 |
| `layout.stations=[(1,[])]` | InvalidValue：指出entries条数与人数不符 |

解析器不接收用户模板或资产；约束核对仅在内部临时纯数据上复用原字段校验，原默认、模板和配置资产不会被写回。原Parse入口继续只产出原子类型结果；逐段取值器通过同源ParseItems取得逐项结果并冻结，见下一节。当前哪些画面实际消费，按本文生效/预留表区分。


## 逐段取值、覆盖容错与只读快照完整参考

配置人员仍在原DialoguePresentationConfig的data十组模板中编辑，填写对话表九个profile列和overrides；当前组件/Prefab接线见本文正式入口，不用改表结构。每段按以下顺序生成独立快照：先取各组真实default；选中具名模板时用该组整套值替换（不是逐字段与default混合）；最后应用本段合法override。未知模板给出组/模板名诊断后回同组default。default缺失/重复、模板重名或原字段范围校验错误会使取值失败且无快照，不能靠override替用户修正配置或猜默认数据。

trigger没有对话表profile列。触发方可调用ResolveTrigger(data,templateName)单独取该组；它只检查trigger组配置，未知名同样给诊断并回default。完整Resolve(data,dialogue,triggerTemplateName)的第三项也是调用方给出，省略时取trigger的default。完整演出快照的数据结构也可解析合法trigger覆盖，但它不写回独立触发快照。当前街景半径/头标实际读NPC Trigger Template的独立快照，因此不能凭完整快照有值就断言能改变外部驱动；参照本文第一节的生效时机。

旧DialogueOverrideParser.Parse的协议保持：任一错误令Success=false、Values为空。逐段取值器通过同一词法/值解析的ParseItems逐项处理，保每项原文/位置及key、问题、原因，跳过错误项并继续应用独立合法项。例如text.autoWait=oops;cg.kenBurnsPanY=0中，autoWait保所选模板值且给诊断，PanY明确为0。不存在的key不会新建参数；类型/范围不符不会钳成默认。

重复按“首次出现保留key”处理：text.autoWait=1;text.autoWait=2应用第一项1，对第二项给DuplicateKey，不静默采用最后值。第一项若已经错，后续同key仍是重复，不能掩盖首错；其它不同key正常应用。分号/引号/转义完全沿原语法；未闭合引号会把剩余文本作为该错误项的尾部，不猜测引号内的分号来恢复条目。合法但含分号/等号的字符串仍须完整引号。本段取值Success可以为true同时有OverrideDiagnostics，表示成功生成“跳过错误项”的快照；配置致命错误则Success=false且Snapshot=null。

快照不是可编辑模板。参数点/颜色分别变成只读X/Y和R/G/B/A对象，站位变成只读人数集合/条目/位置，公开集合不能增删改。修改原配置、原解析的站位数组/盒装点色、下一段的override，均不会改变已经交付的快照。不得把取值结果写回模板或把一段快照当作下一段默认；每段从配置重新取值。

具体CG使用ResolveCg(dialogueSnapshot,cgModel)时，每一列单独处理：非空表值优先，空值回落本段已解析的CG组。横向/纵向漂移互不借值；0是有效显式值，false是有效显式关闭。例：本段CG组X=33、Y=44，表X=0、Y空，结果X=0、Y=44；表X空、Y=0则X=33、Y=0。其它时长/倍率/开关也按各自空值独立回落；曲线沿原Schema别名，未知CG模式/曲线给诊断而不猜默认。此入口只生成数据，不播放CG、计时或执行切场景。
