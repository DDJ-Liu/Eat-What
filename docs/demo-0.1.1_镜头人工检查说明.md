## 调参入口

Project选择 `Assets/Settings/Street/CameraFollowConfig.asset`，在Inspector修改。ScriptableObject在Play中的修改也可能留存；先记原值，检查结束只保留你决定的数值。运行时Cinemachine上的同步字段由程序管理。

| Inspector显示名 | 当前保存值 | 含义与方向 |
| --- | --- | --- |
| Lookahead | 3.5单位 | 稳态水平前视距离，增大看得更远，仍受上限/安全区/边界限制 |
| Lookahead Time | 0.8秒 | 前视目标建立速度；越大越慢。0采用1/60秒最短有限时间常数，保持连续 |
| Damping X | 0.4秒 | 最终相机追踪世界目标X位置的时间常数；越大越慢、运动中滞后越多、停步后追赶越长；0在X上直接追到目标 |
| Damping Y | 0.25秒 | 原纵向Cinemachine阻尼；越大越慢 |
| Stopped Speed Multiplier / `stoppedSpeedMultiplier` | 当前保存0.6；源码预设0.7，两者分列 | 实际停步时普通X/Y响应倍率，无量纲、非负有限；1原模型，0通常暂停，>1加快但不超过本步目标；保留原生极小残差吸附 |
| Recenter Delay | 0.8秒 | 实际脚底停止后的等待 |
| Recenter Speed | 0.65单位/秒 | 回中巡航速度上限；源码默认4不等于当前保存值 |
| Recenter Ramp Time / Recenter Curve | 0.25秒 / SmoothStep | 回中加减速时长及曲线 |
| Dead Zone Width / Height | 0.15 / 0.2 | 基础目标死区比例；水平在实际触边后才取得该方向前视资格，宽度0可立即触发 |
| Max Horizontal Offset | 8单位 | 水平贡献上限；限制目标贡献，目标贡献受此限制，最终相机追上仍需时间 |

正值Lookahead Time仍按Time/3控制目标前视建立；0采用1/60秒最短有限时间常数，目标不会硬瞬移。Damping X/Y分别由Cinemachine对最终世界位置平滑，不在Pipeline再平滑一次。Recenter Speed/Ramp/Curve描述目标回中速度和曲线，最终画面还会经过阻尼，不能把0.25秒目标加减速当最终画面必须同刻停稳的期限。

停步倍率按实际脚底位移和Move Speed Threshold判断，不按松键判断；目标距离、Delay与目标回中曲线都不乘倍率。每帧以当前相机位置和当前目标计算原响应再乘倍率，不把上一帧速度反复乘0.7。不同倍率运行一段后，位置已不同，不能要求同一时刻的两条轨迹速度仍严格保持0.7比。初始化/切换定位、真实瞬移、镜头距离/旋转/Size和Confiner安全纠正不减速。

调参时先记下原值，一次只改一项并用同一路线比较：先用Damping X调整基础追踪软硬，再对比Stopped Speed Multiplier=0.7与1的停步追赶，再用Lookahead/Lookahead Time调整目标前视距离和建立速度，最后按需要调整目标的Delay与回中节奏。本次所有保存参数保持，具体新值由你决定。运行时Cinemachine的Damping显示的是换算值（配置秒数×4.605170186），正式入口仍是配置资产，不直接改CM同步字段。

触边以既有基础跟随目标和当前视口宽度为参考，不跟着前视后的画面中心移动；不要启用Cinemachine原生Dead Zone来辅助判断。触发资格按实际脚底位移方向判断，松键、受阻或纯纵移不算水平换向。新进入/重新启用/真实瞬移会重置资格；修改宽度或视口后，未触发方向使用当前边界，已经触发的同方向资格保留。换向等待时旧偏移会继续平滑变化，不能要求这段画面绝对静止；无旧偏移的新起步死区内应保持横向不跟走。停在死区内部后仍可按原Delay回中。

## 当前验证范围与限制

最新人工旧参数为Damping X=0.5、Lookahead Time=2.4，均保持。离线60Hz、横移6.5/纵移2单位每秒、移动3秒后首个停步样本，0.7组普通X/Y位移约0.080648/0.021821；相同当前状态的原响应约0.115213/0.031173，约为七成。后续逐帧从各自当前状态计算，不能硬比两条已分歧轨迹的速度。新倍率0/0.7/1/2、零/非零基础阻尼、不同步长与两种Confiner顺序离线通过；这些不是实机手感签收。真实Brain混合、场景几何、输入和调度未验证；边界、安全区、FOCUS、视口与纵向构图会影响最终画面。

现有资产不含新字段的实际Unity加载值尚未原生验证；源码预设0.7已离线核对，正常打开项目后请在Inspector确认新值。极小于Cinemachine原生Epsilon的残差仍可直接吸附，因此倍率0不取消这一数值终点行为。

已有接线/无新增Error/驱动有输出的历史事实保留，旧行为探针冻结，不作为当前验收门。角色描边保持暂停；未安排新引擎行为验收或打包。检查后直接反馈“镜头检查通过”，或对应行及操作；通过后再安排新目录打包。
