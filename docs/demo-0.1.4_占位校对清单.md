### 重复交谈和已聊灰态

1. 用测试进度完成一段普通对话，观察该段相关Talk标记的灰态。
2. 再与同一绑定交谈，应重新从同段首句开始，灰态不代表禁止交谈。
3. 想比对第二轮换内容，显式切换状态绑定；同一轮b→b2续接不是“下次交谈才接b2”。
4. 所有绑定同段的NPC共享该段已聊状态；切状态可能清此段。清记录前后核对必须先记录操作，避免把被Apply清掉误报成落盘失败。
