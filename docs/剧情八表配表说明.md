本轮离线结果：当前合成专项231检查/56案例及旧相关回归通过，当前正式22表仍0error/44warning/1info。正式数据与工作簿原值未修改；两次新增测试期望失败留档，不影响这里对warning/info级别的解释。缺场景清单的UNVERIFIED仍保持，不能据此视为已验证游戏内容。

2026-11-15另局部核对N009专项校验实现。正式导入与`DevTools/DataTables/Validate-DataTables.ps1`默认启用Schema v2.5作者规则。主键、必填、枚举、本地化key，以及CSV解析/数值类型/NaN等真实错误仍是error并阻断。新表专项引用与V13～24其余问题为warning，14b/16b为info，不阻断；原通用严格Validate API继续服务已有通用调用。每条报告含规则、表、CSV真实行号和列，按提示修正源表，工具不会代改非空单元格。

填写时重点检查：first_line/next_line构成无环完整链且归属标签一致；出场从01连续且角色有立绘；位置和站位同时填时位置优先并有info；normal/story的speaker必填，没立绘的旁白可不在出场名单。命令语法/签名、等级限制与scene_switch只放on_end由共享解析器核对；actor_emote是完整版预留info，并行方式的wait也提示info。overrides错误、未知key/类型和真实配置中缺模板给warning，等待方式取实际tier配置及覆盖，不额外规定wait秒数正负范围。

角色/CG/场景资源只按已批准目录和精确文件基名核存在/唯一性，不代表已导成Sprite或接好Prefab。未提供演出配置或文件清单时报告`NARRATIVE_UNVERIFIED`，不能据此认定所有模板或资源缺失；本批尚未创建演出配置资产，需后续调用方提供实际N006数据。每场景的各状态应填完整条目，actor专用的anchor_id/facing/dialogue_id/ambient_pool/marker不放在object/exit条目；带实例后缀的actor仍引用基础角色。场景对象、预摆实例、锚点/出口存在与触发区移除属于V25，当前不检查。正式八CSV仍零业务行；干净合成夹具的零诊断不替代真实内容或旧场景UNVERIFIED状态。

最后实际核对：2026-11-15，仅N004源码、105列schema、正式22表工作簿及离线往返/回归，不代表全项目或游戏表现验收。八份正式CSV只有表头/零行；主xlsx现22页/224说明，旧14页内容、类型、公式、结构及119条旧备注保持。注释/格式已安全发布，正式22表0错误/44警告/1信息和四旧完整入口通过并经CONTROL独审；保留场景清单UNVERIFIED，Excel客户端显示尚未签收。维护应沿本说明与现工具，不重放已完成的扩表/注释/格式发布。本阶段不执行命令、创建配置资产、绑定立绘/Prefab或接入剧情状态机。

每列的实际用途和填法以对应schema.description及生成的中文表头注释为准。修改原工作簿时保留已填值、类型、公式和用户自建页；空表只建立第一行表头，不填猜测的角色、台词或场景ID。操作脚本、冻结SHA/备份及事务发布见[Authoring说明](../DevTools/DataTables/Authoring/README.md)。

| 表与CSV位置 | 键与主要用途 | 填写要点 |
| --- | --- | --- |
| Narrative/Characters.csv | character_id，chr_前缀 | name_key留空不显示名字框；旁白也是普通角色。立绘留空的角色不能用于立绘出场名单。portrait_offset_x为图宽比例，范围-0.5～0.5；offset_y从底边0到顶边1；portrait_scale为正数。 |
| Narrative/Dialogues.csv | dialogue_id，dlg_前缀 | tier为ambient/normal/story；first_line必填。当前展开cast_01～04，每位都有station/pos_x/pos_y/scale/order。位置为2560×1440基准屏幕像素，原点为屏幕底边中点，右/上为正；直接位置、站位名、人数默认站位的取值次序由后续消费者落实。更多人须配套扩schema、行类型和列，四组不是永久人数上限。 |
| Narrative/DialogueLines.csv | line_id，ln_前缀 | dialogue_id是所属段标签，next_line为空表示末句；text_key必填。normal/story的speaker必填，ambient可空；name_override_key仅覆盖本句名字。commands原样存储，不在导表时执行。 |
| Narrative/CGs.csv | cg_id，cg_前缀 | cg_sprite必填。transition_mode为black_fade/cross_fade；fade_in/out及ken_burns_duration单位秒且非负；pan_x/pan_y为基准屏幕像素，右/上为正；曲线为linear/quadratic/smooth_step/ease_in_out。 |
| Street/Scenes.csv | scene_id，scn_前缀 | scene_type为street/interior；is_small_room必填true/false；scene_asset填无路径、无扩展名的场景名；default_state须在同scene_id的SceneStates里存在。 |
| Street/SceneStates.csv | scene_id+state_id组合键 | state_id不带前缀，只需在本场景内唯一；不同场景可以都用morning。story_stage/description/switch_source是说明内容。 |
| Street/SceneStatePlacements.csv | scene_id+state_id+kind+target组合键 | kind为actor/object/exit；active必填。角色target可带#实例后缀，facing为left/right，marker为none/talk/story。角色已有预摆实例时anchor_id可空以保留位置，没有实例时必填；此条件需后续场景上下文检查。每个状态填完整表，不按差量理解。 |
| Street/AmbientPools.csv | pool_id，amb_前缀 | dialogue_ids用英文分号;分隔，至少一条，均须引用tier=ambient的段；scope/comment为说明。 |

所有ID与引用区分大小写；引用填写目标ID，不写显示名。名字和正文的loc_key须在Localization配置。父段等级、场景内状态和气泡池引用由共享校验器检查；链标签与顺序一致性、预摆实例、真实场景/资源状态及运行效果仍有后续上下文检查，单次导入成功不能代替它们。T14.preset_tools及旧表定义/数据保持。

允许空的数值和布尔列保留“未指定”，与显式0/false不同。CG横/纵漂移可各自留空回落；不把空CG开关自动写成false，也不在CSV导入时套演出配置默认值。Characters缩放/偏移等运行回落按Schema及演出配置实现，本阶段只保留输入状态。九个profile留空按后续default取值；overrides及命令文本的写法见[对话参数说明](参数调整说明_对话.md)，本阶段不执行。comment保留在CSV/Excel中，沿既有导入约定不写入生成行。

立绘、CG与街上形象字段只填文件基名，保留成品大小写，无路径、扩展名和多余空白。按[已批准目录方案](剧情资源目录方案.md)在以下目录及其占位子目录精确查找：

- 立绘：Assets/Sprites/Narrative/Portraits；占位Assets/Sprites/Narrative/Placeholders/Portraits。
- CG：Assets/Sprites/Narrative/CGs；占位Assets/Sprites/Narrative/Placeholders/CGs。
- 形象：Assets/Prefabs/LongLoop/NPC/Visuals；占位该目录的Placeholders。

缺失、大小写不符、非法路径/扩展名或多个同名匹配均给出未解析诊断，不挑第一项，不自动创建目录/占位，不迁移或绑定素材。留空不强制选占位。素材导入仍须按已批准目录方案另行逐项审定。

DATA扩表使用New-AuthoringWorkbook的AddSchemaTables八表清单；当前八个CSV/表页已存在，后继保持其已保存状态。注释步骤同时给UpdateSchemaTables和InitializeSchemaTables传这八表：旧14页不进入更新循环，其旧说明、示例、人工备注及回复保留；完整22表表头和全局内容/注释审计仍执行。表名必须精确大小写、合法、无重复，初始化不得超出更新名单。省略更新名单仍按原行为更新全表，任何选中表的未知或人工编辑备注仍拒绝替换，不能仅凭AI189标记认定归属。已有页表头必须精确相符。随后生成格式候选，冻结和复核原源、备份及候选，按既有授权事务发布。空sheet遇已有目标CSV时跳过并保留原字节；目标缺失且baseline无文件或只有合法相同表头、无配置数据时，可生成header-only CSV。baseline有配置数据时不把空sheet写成清空文件，也不从baseline回填旧数据；编码/表头/未知IO错误如实失败。新建表头在回执单列来源，业务数据行仍为零。当前临时夹具已证明旧14页、含公式/类型/hidden未知页保护和八表原文往返；新增页在用户Excel客户端的注释/条件格式显示尚未由本CODE阶段人工验收。命令参数见[Authoring说明](../DevTools/DataTables/Authoring/README.md)。
