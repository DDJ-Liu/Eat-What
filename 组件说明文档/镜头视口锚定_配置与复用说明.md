# 镜头视口锚定：配置与复用说明

最后实际核对：2026-09-23  
核对范围：`CameraViewportAnchor` 源码、ShortCycle CameraPan 时序、PresentationSet 的焦点/门控和 bounds 计算；未进入 Unity、未修改场景，实际画面与 Inspector 接线由 FIX-T5-R1b 验证。

## 功能

`CameraViewportAnchor` 把一个世界空间对象固定在指定镜头的 viewport 位置。镜头平移、正交尺寸或宽高比变化后，它会在同一帧的 `LateUpdate` 重新计算世界坐标；对象的 Z、缩放和旋转不被改写。

把视觉、`Collider2D`、`Button_MouseInteract`、动作绑定和状态门控放在同一个 `Anchored Root` 下。这样画面与命中区会一起移动，不会出现“按钮看得到但点不到”或命中区滞后一帧。

## 在哪里配置

在要固定的世界空间按钮根对象上添加 **Camera Viewport Anchor**。组件应位于 `Anchored Root` 本身或其父级；ShortCycle 的 Set bounds 会据此排除跟镜头移动的控件 Renderer，避免控件把书本或厨房的世界 bounds 拉宽。

| Inspector 字段 | 单位/范围 | 默认值 | 画面影响 |
|---|---|---|---|
| Target Camera | Camera 引用 | 空 | 必填。明确指定跟随的镜头；组件不会使用 `Camera.main` 或场景搜索兜底。 |
| Anchored Root | Transform 引用 | 空（运行时等同组件自身） | 正式接线建议显式填写。该根及其子物体整体移动，视觉和 Collider 必须同属此根。 |
| Viewport Anchor | X/Y 归一化坐标，0–1 | (0,0) | (0,0) 为左下，(0.5,0.5) 为中心，(1,1) 为右上。 |
| Inward Viewport Inset | X/Y 归一化距离，0–1 | (0,0) | 从所选边缘向画面内缩。数值越大，控件离边缘越远；会自动钳制在 viewport 内。 |
| Preserve Initial World Z | 开关 | 开 | 开启时首次启用记录 Anchored Root 的世界 Z，之后重复启用仍回到该平面。 |
| World Plane Z | 世界单位 | 0 | 仅在关闭 Preserve Initial World Z 时生效，用于显式指定目标世界平面。 |

## ShortCycle 建议接线（交给 FIX-T5-R1b）

- `Escape_Button_TUNE` 与 `Phase1_Kitchen/Return_Button_TUNE`：各自在保留现有 Sprite、Collider、鼠标/键盘、ActionBinding 和 StateGate 的根对象上添加组件。
- `Target Camera`：显式连接 ShortCycle 的受控 Camera。
- `Anchored Root`：显式连接按钮自身根对象，确保视觉和 Collider 同移。
- 建议起点：`Viewport Anchor=(0,0)`，`Inward Viewport Inset=(0.04,0.06)`。这是按既有左下安全距离给出的调参起点，不是把当前故障位置当目标；R1b 应在 16:9 和另一代表宽高比下以实际 tight bounds 调整。
- 保持 `Preserve Initial World Z=On`，不要用锚定组件修正缩放或排序层。
- 按钮何时显示、何时可点击仍由现有 PresentationSet、StateGate、InteractionLayer、Modal 和输入锁决定；锚定只负责位置，不会绕过业务门控。
- 只有物理 `ClueBoard_Group` 的 PresentationSet 可启用 `Keep Visual Active Across Spaces`。该选项只保持明确指定的结构视觉，不应在普通 Shared Set、Modal 或按钮 Set 上批量启用。

## 时序和限制

- 组件执行顺序为 `DefaultExecutionOrder(10000)`，在 CameraPan 协程写入 Camera 后于 `LateUpdate` 跟随，避免一帧拖尾。
- 初次启用、重复启用、镜头移动、zoom、aspect 变化和非原点父 Transform 均重新按世界位置求解。
- 组件每帧只读取已序列化的 Camera/Transform，不进行 `Find` 或 Camera 搜索。
- Camera 必须能够用 `ViewportToWorldPoint` 在指定 Z/平面求点；当前 ShortCycle 是正交镜头。若改为透视镜头，须重新验证深度语义和遮挡。
- 跟镜头移动只保证位置；安全区、不同语言文字宽度、Sprite tight bounds 和视觉构图仍需在 Unity 中人工验收。

## 快速检查

1. 平移镜头时 Sprite 与 Collider 同帧同移。
2. 改正交尺寸和 Game View 宽高比后，控件仍保持同一 viewport 边距。
3. 重复进出 P0/P1 后 Z、scale、状态门控不变。
4. 打开 Modal 时底层按钮不可穿透；过渡锁期间不可点击。
5. `ShortCycleLayoutAudit` 输出 `fixT5ViewportAnchors`、`fixT5ViewportAnchorInvalidPaths`、`fixT5CluePersistentVisual` 供只读复核。
