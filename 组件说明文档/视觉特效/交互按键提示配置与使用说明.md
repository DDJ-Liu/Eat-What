## 用途与接线

在后续独立被动HUD根上挂 **InteractionPrompt**，不要放在另一个Canvas内部，以保证本件拥有独立Overlay排序。选择谁可交互、何时按键、对话是否允许均由调用者负责；调用 `Show(anchor, localizationKey)` 显示/换目标，返回false时读LastDiagnostic。`Hide()`淡出；同一挂点/同一key重复Show不会重开淡入。同一时刻只有一个目标，切目标复用同一提示框，已完全显示时直接换内容、不再从0闪一次。调用方可用同件显示「前往…」等动作，没有写死交谈文案。

提示运行根为 `InteractionPromptCanvas_Runtime`，Screen Space Overlay，2560×1440参考像素、按高度缩放。每帧只用显式World Camera投影挂点位置，再换算成Canvas参考坐标；不复制挂点或镜头的纵深/缩放。框为固定420×64参考像素，键帽64×48，统一字体28，动作文字长时省略，不因设备切换重排尺寸。当前层次约定：气泡100 → 提示150 → 压暗/对话HUD200。没有GraphicRaycaster、EventSystem或UGUI交互控件，所有Image/TMP的Raycast Target关闭，CanvasGroup不交互/不拦射线；本件不是新的点击输入通道。

外观为运行时程序生成的64×64圆角贴图/九切片Sprite，圆角底加键名文字，不读取外部新美术资产。键盘与手柄使用相同框/键帽/文字位置，只有键帽文字变；当前手柄确认名A是占位，不代表已接手柄确认硬件。

## Inspector字段

字段在挂有InteractionPrompt的HUD根上修改。源码默认值与当前场景样例分开：本卡**没有**保存场景样例；下表均为源码默认或明确接线建议。

| Inspector显示名 | 默认 / 单位 / 有效范围 | 用途与变化 | 生效方式 |
| --- | --- | --- | --- |
| World Camera | None，Camera引用 | 接渲染世界挂点的相机；Street后续接Cam_Street。只读投影，非Canvas渲染相机。缺失时Show=false | 运行时读取；换引用改变跟随投影，不改框像素尺寸 |
| Input Provider | None，MonoBehaviour | 接实现Toolkit.IGameInput的现有提供者；空时按Keyboard显示。只读CurrentDevice，不读Interact/移动/Look/鼠标输入 | 首次启用且接口尚未配置时解析；以后更换引用用ConfigureInput(interface)显式更新 |
| Font Asset | None，TMP_FontAsset | 必须显式接既有字体；建议与气泡相同 `Assets/Fonts/Heavy/ShortCycle_Heavy_WithFallback.asset`。空值Show=false，不猜TMP_Settings | 创建运行提示时绑定，之后改需重建；不改字体资产 |
| Font Material | None，Material | 空时用Font Asset共享材质，显式值覆盖引用。创建TMP时先fontSharedMaterial后font | 创建时绑定；不实例化/改写共享材质 |
| Fade In Time | 0.08秒，有限且≥0 | 从当前量淡入到1；越大越慢，0状态立即到1 | 创建状态时读取，改后重建提示 |
| Fade Out Time | 0.08秒，有限且≥0 | 从当前量淡出到0，结束释放目标；越大残留越久，0状态立即隐藏 | 同上；默认Update使用unscaledDeltaTime |
| Anchor Pivot | (0,0.5)，归一化，两轴0～1 | 哪个框点对准挂点。默认左侧中点，从挂点向右展开；(0.5,0.5)使中心对准，(1,0.5)向左展开 | 创建运行框时读取，修改需重建 |
| Keyboard Key Caption | E，短字符串 | 显示键盘交互键名，不修改实际按键绑定。现输入默认交互E；若调用方重绑，要同步该显示值 | 创建状态时读取 |
| Gamepad Confirm Caption | A，短字符串 | 手柄确认键名占位；可按未来手柄方案改短名称，槽位与文字布局始终相同 | 创建状态时读取；不接硬件 |
| Sorting Order | 150，无单位整数，-32768～32767 | 整个提示画布排序；当前应高于气泡100、低于压暗/对话HUD200。增大整体更靠上 | 创建Canvas时读取，修改需重建 |

重建指禁用/重新启用本组件后由调用者再次Show；只清理本件自己的运行Canvas、Sprite、Texture和显示状态，保留外部挂点/字体/材质。原生Destroy帧末执行，Canvas先停用，避免一帧同时显示两份。挂点被销毁时清掉状态；挂点停用、位于相机后方或相机无效时不显示投屏内容。

每帧默认自动推进；公开Advance只用于明确接管驱动或离线检查，正常Update之外不要重复推进。同一目标重复Show不延长淡入，重复Hide不延长淡出；过渡途中重新Show从当前透明度续接。Show/Hide不承担目标选择、锁或执行交互行为。

## 设备与本地化边界

当前 `LegacyInputProvider.CurrentDevice` 已能报告Keyboard/Gamepad，沿用其现有鼠标/右摇杆采样判定。提示不改变判定，也不新增手柄确认键读取；实际Gamepad交互仍待以后输入接入。切设备只改键帽文字；动作本地化key、目标、透明度和固定Rect布局保持。

文字直接由现 `LocService` / `LocTextCatalog` 查询，实际TMP沿用 `LocalizedText.ConfigureContent`。key缺失时保留原 `#key#` 文本和原目录的去重warning，不清空、不替换为交谈、不隐式写表。补齐/重配本地化后当前提示随刷新读取新内容。真实长token可能因固定宽度省略；完整key可从调用方或本地化日志定位，不通过加宽设备专属布局绕过问题。
