# 醚质泡泡折射：配置与使用说明

最后实际核对：2026-09-15  
核对范围：`EtherBubbleDistortion2D`、`EtherBubbleEmitter2D`、`SceneColorCapture2D`、`VisualEffectsLabDriver`、Soft/Obvious 预设、当前泡泡 Prefab/材质、统一 VisualEffectsLab 接线，以及 AI81 的 Unity/GPU/用户视觉验收记录。

本效果把专用背景相机捕获的一张场景色纹理映射到泡泡 Sprite 上，再用径向波纹和流动偏移扭曲采样位置，最后叠加柔边与彩色边缘。所有泡泡共享同一捕获 RenderTexture；单个泡泡用 `MaterialPropertyBlock` 写自己的参数，不需要逐泡泡复制材质。

用户于 2026-09-14 已确认泡泡视觉相关验收通过。该结论只覆盖统一 Lab 的试样和当时的运行条件；正式游戏场景尚未接入，换分辨率、换镜头或换背景层后仍需按本文重新核对。

## 1. 在哪里配置

- 整体发射、数量、速度、寿命和预设：选中发射器对象，在 **Ether Bubble Emitter 2D** 上配置。这是日常调参的主要入口。
- 捕获质量与背景层：选中捕获对象，在 **Scene Color Capture 2D** 上配置。这里影响所有共享该捕获源的泡泡。
- 单个泡泡模板：打开泡泡 Prefab，在 **Ether Bubble Distortion 2D** 上配置材质、捕获引用、视觉参数和实例运动。由发射器生成时，发射器会覆盖模板的视觉、半径、速度、寿命和捕获源，因此不要把运行时变化误认为 Prefab 被修改。
- Lab 操作：启用 `DebugAndReferences`，选中带 **Visual Effects Lab Driver** 的对象。组件标题行右侧点 **⋮**，或右键组件标题，使用 Context Menu；也可进入 Play 后用快捷键。

统一试验场景是 `Assets/Scenes/ToolTests/VisualEffectsLab.unity`。泡泡当前只作为 Lab 试样，不应因调试直接修改正式场景、共享渲染设置或 Build Settings。

## 2. Ether Bubble Emitter 2D：正式调参入口

### 接线字段

| Inspector 字段 | 当前 Lab 值/要求 | 作用 |
| --- | --- | --- |
| **Mouth Anchor** | `MouthAnchor_TUNE` | 每个泡泡的世界坐标出生点。移动它会改变后续新泡泡的起点。 |
| **Spawn Parent** | `BubbleSpawnParent` | 池化实例的父对象。用于整理层级，不应指向会意外缩放或隐藏泡泡的对象。 |
| **Bubble Prefab** | 项目泡泡 Prefab | 必须带 **Ether Bubble Distortion 2D** 和 `SpriteRenderer`。 |
| **Capture Source** | 同一 Lab 捕获组件 | 所有泡泡从这里读取背景 RT；为空或未形成有效帧时泡泡安全变透明。 |

以上是高级接线，不是画面风格参数。不要为了调颜色或强度更换引用。

### 发射、运动与寿命

| Inspector 字段 | 默认/当前 Lab 值 | 有效范围与单位 | 调大/调小后的表现 |
| --- | ---: | --- | --- |
| **Max Bubbles** | 16 | 1～64，个 | 同屏池化泡泡上限；调大可增加密度，也增加 Sprite 绘制和透明混合成本。调小会停用超过新上限的活跃泡泡，但已建立的池列表可保留以供复用。 |
| **Emission Interval** | 0.7 | 0.05～10，秒 | 连续发射的间隔；越小越密，越大越稀。约略密度同时受寿命和上限限制。 |
| **Auto Emit On Enable** | 开启 | 开/关 | 开启时组件启用后自动连续发射；关闭时需用菜单、快捷键或脚本调用开始/单发。 |
| **Bubble Radius** | 0.8 | 0.05～20，世界单位半径 | 越大泡泡越大；组件把直径设为半径的 2 倍。过大会更容易暴露纹理采样和屏幕边缘问题。 |
| **Movement Velocity** | (1.4, 0.8) | 每轴 -100～100，世界单位/秒 | X 控制水平漂移，Y 控制升降；负值反向。速度越大，同寿命内移动距离越长。 |
| **Bubble Lifetime** | 5 | 0.05～120，秒 | 越长同屏积累越多；越短消失越快。连续发射的理论在场数量约为 `寿命 ÷ 间隔`，但不会超过 **Max Bubbles**。 |
| **Initial Preset** | Soft | Soft / Obvious | 组件启用时应用的视觉预设。切换预设会同步到当前活跃泡泡。 |

常用密度起点：当前 `5 ÷ 0.7 ≈ 7` 个自然存活泡泡，低于上限 16。想增加密度时先小幅减小 **Emission Interval** 或增加 **Bubble Lifetime**，再确认是否真的需要提高 **Max Bubbles**；三者同时增大会迅速把同屏数量推到上限。

### Soft 与 Obvious 预设

| 字段 | Soft | Obvious | 画面影响 |
| --- | ---: | ---: | --- |
| **Distortion Strength** | 0.012 | 0.032 | 折射位移幅度；绝对值越大，背景扭曲越强。负值会反转位移方向，0 关闭折射位移。有效范围 -0.08～0.08。 |
| **Wave Frequency** | 5 | 8 | 泡泡内部径向波纹密度；越大环纹越密，越小越舒缓。范围 0.5～20。 |
| **Wave Speed** | 0.7 | 1.4 | 径向波随时间移动的速度；绝对值越大越快，负值反向。范围 -8～8。 |
| **Flow Speed** | 0.35 | 0.75 | 环绕流动的速度；绝对值越大越活跃，负值反向。范围 -4～4。 |
| **Softness** | 0.20 | 0.14 | 边缘淡出的宽度；越大过渡越宽、更柔，越小边缘更利落。范围 0.01～0.5。 |
| **Rim Color** | (0.55,0.88,1.15,1) | (0.65,0.95,1.4,1) | 边缘色；支持 HDR 亮度，通道运行时限制在 0～8，颜色 alpha 限制在 0～1。 |
| **Rim Intensity** | 0.55 | 1.15 | 边缘亮度倍率；越大越亮，0 不贡献边缘亮度。范围 0～4。 |
| **Rim Alpha** | 0.28 | 0.55 | 边缘透明强度；越大越实，0 隐藏边缘。范围 0～1。 |

Soft 适合背景细节仍要清楚、泡泡只是轻微扰动的场景；Obvious 适合演示或需要更容易看出效果的场景。二者是项目预设和建议起点，不是每个正式场景的视觉保证。

联动注意：

1. **Distortion Strength** 只控制背景位移，不等于泡泡整体可见度。即使它为 0，边缘仍可能可见。
2. 要做“完全不改变原画面”的折射对照，应把形变设为 0，并同时把 **Rim Intensity** 或 **Rim Alpha** 设为 0。
3. **Rim Color** 的 alpha、**Rim Intensity** 和 **Rim Alpha** 会共同影响边缘强度；排查时先固定颜色 alpha=1，再分别调另外两项。
4. **Softness** 越小、边缘强度越高，轮廓越醒目，也越容易显得硬或抢画面。

## 3. Ether Bubble Distortion 2D：Prefab 与单实例

| Inspector 字段 | Prefab 当前值 | 说明 |
| --- | --- | --- |
| **Bubble Material** | `Assets/Materials/VisualEffects/EtherBubble.mat` | 使用 `EtherBubbleDistortion2D.shader` 的共享材质。为空时无法输出本效果。 |
| **Capture Source** | None | Prefab 中故意留空，由发射器在实例激活时注入；不要仅因 Prefab 显示 None 就补成场景引用。 |

| **Movement Velocity** | (1.4,0.8) | 每轴运行时限制 -100～100，世界单位/秒；发射器生成时覆盖。 |
| **Lifetime** | 5 | 0.05～120 秒；发射器生成时覆盖。 |

这个组件还保存年龄、暂停、效果启停和捕获有效性等运行状态。它们不是 Inspector 的第二套正式配置，不要通过调试器强改来替代发射器入口。

## 4. Scene Color Capture 2D：共享捕获质量

### 接线与质量参数

| Inspector 字段 | 默认/当前 Lab 值 | 有效值 | 影响 |
| --- | --- | --- | --- |
| **Main Camera** | Lab 主相机 | 显式引用 | 决定目标像素尺寸和相机状态来源。 |
| **Background Camera** | Lab 背景捕获相机 | 显式引用 | 只渲染指定背景层；运行时会同步主相机所需状态，停用/销毁时恢复原状态。 |
| **Background Layer Mask** | TransparentFX（数值 2） | LayerMask | 决定哪些对象进入折射背景。泡泡、角色、前景和调试字不应进入，否则可能递归或把前景错误折射。 |
| **Render Scale** | 1 | 0.25～1 | RT 宽高分别为主相机像素宽高乘此值。0.5 时像素数和约略显存为 1 的四分之一，但折射细节更糊。 |
| **Anti Aliasing** | 1 | 1、2、4、8 | 捕获 RT 的 MSAA；非支持值会归一化到合法档。提高可能改善边缘，但增加设备负担，需目标平台复验。 |
| **Capture Enabled** | 开启 | 开/关 | 关闭后捕获无有效帧，泡泡透明；不是冻结旧背景。 |

每个捕获组件只持有一张 ARGB32、双线性、Clamp、无 mip 的 RT，所有泡泡共享。AI81 验收时 2560×1440、Render Scale=1 的一张 RT 记录为 14,746,112 字节；这是该次 Editor 数据，不是所有平台固定值。显存与 `Render Scale²` 近似成正比。

Lab 的 Lit 2D 后景和 `GlobalLight2D` 必须处于 TransparentFX 层。若背景相机看不到全局光，捕获 RT 可能发黑；先查 Layer/Mask，不要用提高边缘强度掩盖。捕获源为空、相机不可用、尺寸为零或尚无有效帧时，Shader 设计为输出透明，避免黑矩形和旧帧残留。

## 5. Lab 操作、快捷键与预期变化

先启用 Hierarchy 中唯一 `DebugAndReferences`，再进入正常 Play。选中 **Visual Effects Lab Driver**，在组件标题行右侧 **⋮** 或右键组件标题可看到以下命令：

| Context Menu | 快捷键 | 预期变化 |
| --- | --- | --- |
| **Emit One Bubble** | `1` | 从 Mouth Anchor 单发一个泡泡。 |
| **Burst 8 Bubbles** | `8` | 一次尝试发射 8 个，受暂停、引用和上限限制。 |
| **Burst 16 Bubbles** | `9` | 一次尝试发射 16 个，最多达到 **Max Bubbles**。 |
| **Toggle Continuous Emission** | `Space` | 只切换持续产生新泡泡；关闭后已有泡泡仍继续运动至寿命结束。 |
| **Toggle Pause** | `P` | 暂停/恢复发射计时，并暂停/恢复活跃泡泡的移动和年龄。 |
| **Toggle Distortion** | `D` | 切换活跃泡泡的形变与边缘效果；用于原画面对照。 |
| **Apply Soft Preset** | `F1` | 活跃泡泡和后续新泡泡切为 Soft。 |
| **Apply Obvious Preset** | `F2` | 活跃泡泡和后续新泡泡切为 Obvious。 |
| **Clear All Bubbles** | `C` | 立即停用活跃泡泡，但保留池对象以供复用。 |

**Sample Angular Speed** 与 **Sample Bob Amplitude** 只驱动 Lab 的透明样本旋转/上下浮动，不是泡泡产品参数。角速度 Inspector 有效范围 0～8 度/秒，当前场景为 8；源码初始化字面值 25 会在校验时限制到 8。浮动幅度默认/当前为 0.25，范围 0～2 世界单位。Driver 禁用时会恢复原发射、暂停、效果、预设和样本 Transform，并清空泡泡。

## 6. 推荐配置示例

### 轻柔常驻

- **Initial Preset**=Soft
- **Emission Interval**=0.8～1.2 秒
- **Bubble Lifetime**=4～6 秒
- **Max Bubbles**=8～12
- **Render Scale**=1；性能不足时先试 0.75，再检查边缘与背景清晰度

适合让泡泡存在感较低。正式使用前按实际镜头和背景确认形变不是过弱或难以识别。

### 明显演示

- **Initial Preset**=Obvious
- **Emission Interval**=0.35～0.7 秒
- **Bubble Lifetime**=4～6 秒
- **Max Bubbles**=16

适合参数检查和演示 A/B。若画面太花，优先回 Soft 或降低形变/边缘强度，不要只缩短寿命。

## 7. 常见问题排查

- 完全看不到泡泡：检查发射器四个显式引用、是否暂停、活跃数是否已达上限、Prefab 的 SpriteRenderer/材质，以及泡泡对象的 Layer/Sorting。
- 出现透明而不是折射：检查 **Capture Enabled**、主/背景相机是否有效、目标尺寸是否非零、捕获是否已经完成一帧。透明是安全降级，不一定是 Shader 编译失败。
- 捕获画面黑：确认后景和 `GlobalLight2D` 在 TransparentFX，且 **Background Layer Mask** 包含该层；同时确认背景相机没有被其它脚本覆盖。
- 前景也被折射或出现递归：前景、角色和泡泡不应放进捕获层；排序顺序不能替代 GameObject Layer/cullingMask。
- 连续发射关了但泡泡还在动：这是 **StopEmission** 的预期，只停止新发射。用暂停冻结，用清空立即移除。
- 调了 Prefab 但运行实例没变化：发射器激活实例时会覆盖视觉、半径、速度、寿命和捕获源；应在发射器上调，或明确修改预设合同。
- 降低上限后池数量没缩回：上限限制的是活跃泡泡；已分配对象可保留以避免重复分配。用活跃数判断画面，不要把池列表长度当同屏数量。

## 8. 性能、裁切与验收边界

- 主要固定成本是共享背景相机和一张捕获 RT；主要随数量增长的是泡泡 Sprite 绘制与透明混合。AI81 的 16 泡泡样例在当次 Editor 记录为增加 2 个 draw call / 32 个三角形，只能作为该场景参考，不能替代 Player/目标设备性能测试。
- 泡泡接近屏幕边缘时，折射采样会受屏幕 UV 边界和 Clamp 影响；半径、速度、镜头和 Spawn 点变化后要重新观察边缘。
- 本实现不做任意深度自动选择，也不做泡泡递归折射。捕获层必须由场景配置人员明确维护。
- 统一 Lab 已完成 1/8/16、连续发射、暂停/恢复、清理、禁用重进、Soft/Obvious、效果开关、前景隔离、相机/边缘、RT 生命周期和用户视觉签收。历史视频参考未观测；用户后续已接受整体泡泡视觉，这两项事实不冲突。
- 正式场景接入、更多 Game View 分辨率/宽高比和目标设备成本仍是后续工作；不能把 Lab 通过写成正式场景已上线。

研发与验证背景见 `DevTools/Rendering/VisualEffectsLab.md`。其中的参数表是 Lab 快照；日常配置以本文和当前 Inspector 为准。
