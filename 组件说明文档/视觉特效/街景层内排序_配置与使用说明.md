# 街景层内脚底Y排序：配置与使用

最后实际核对：2026-11-04；范围为AI427的YSorter/YSortMath、Inspector字段、现六层名及实际源码离线测试。当前没有在Street挂载或完成真实绘制顺序验收；前后临时精灵、连续Console与作者场景clean仍待ENGINE窗口，最终观感由用户验收。

同一Sorting Layer中，脚底世界Y越大越靠后，Y越小越靠前。组件计算 `order = Base Order − round((foot.worldY + Depth Offset) × Precision_TUNE)`，只写一个明确目标的Order in Layer；从不改Sorting Layer ID/层名、材质或透明度。Base Order是手工保存的决胜值，始终从该字段重算，不把上一帧输出当新基准。

组件只在运行时计算，Edit模式不会自动重排保存资产。

在当前Potato的审定对象上挂 **Y Sorter**；ENGINE先确认它实际使用的Renderer或已有SortingGroup，再填目标。脚底应绑定未被视觉缩放/偏移改变的角色移动根或独立脚底锚点；不要填身体中心、FOCUS跟随点或DepthScale正在补偿的视觉根。组件挂在Visual_TUNE也可以，但 **Foot** 仍显式引用独立脚底；没有引用时不猜本对象pivot。

| Inspector字段 | 默认值／单位 | 配置与表现 |
| --- | --- | --- |
| **Target Sorting Group** | 空；已有SortingGroup引用 | 有有效引用时优先，唯一写此Group的sortingOrder；不会逐个改其子Renderer，或因Group当前enabled=false改选其它对象。不开启、关闭或新增Group。 |
| **Target Renderer** | 空；精确Renderer引用 | 仅Group为空时采用，唯一写该Renderer。两者都空报MissingTarget、不自动查找父/子Renderer。 |
| **Foot** | 空；场景Transform | 提供脚底世界Y；必须明确填写，空时报MissingFoot、保持原/最后自有值。与本组件宿主的位置独立，避免视觉缩放反馈。 |
| **Base Order** | 0；整数Order | 手配稳定决胜基准。接入前将目标当前保存的手配Order作为候选核对并明确填写，不默认替用户重置为0；同量化Y时值较大的对象更靠前。停用恢复点另外捕获，不能把它误当每帧Base Order。 |
| **Precision_TUNE** | 100；Order/世界单位 | 越大，Y变化反映得越细且占用Order范围越快。100约对应每0.01u一个刻度；0只输出Base Order。必须有限且≥0，运行API传负数/NaN/∞则报InvalidInput、不写新值。 |
| **Depth Offset** | 0；世界单位 | 排序专用预留偏移，与脚底Y相加。正值视作更靠后、Order减小；负值视作更靠前。它不移动对象，不使用DEPTH/FOCUS，也不实现区域/抬高平台自动判定。 |
| **Bake On Start** | false；开关 | false：检查脚底/参数变化后重算，相同输入不重复写。true：每次启用/明确换目标后，在Start或重启时只采样一次；之后位置及普通参数变化不自动更新。要更新静态值，可停用再启用，或由工程调用Rebake；不必给静态对象每帧重算。 |

例：Base Order=10、Precision=100、Offset=0时，脚底Y=0/2/−2分别得到10/−190/210。同Y且Base Order=11的对象比Base=10高1；若Base和量化Y都相同，本组件不额外规定它们的先后。取整使用双精度中间值、就近舍入且正负半数取偶数，例如Precision=1时，Y=0.5/1.5/−0.5/−1.5的取整结果为0/2/0/−2；实际输入仍是Unity的float值。

最终结果饱和到Unity的−32768～32767后才转整数，极端坐标/精度不会整数溢出反向。触顶时Status=Saturated，多个物体可能落到同一极限值；调小Precision或调整手配Base来分配可用范围，不自动改层名或建筑布局。非有限Y/Offset及非法Precision报InvalidInput并保持最后自有Order，恢复有效参数后再更新。Status/AppliedOrder为运行探针读回属性，不是Inspector调节字段。

组件启用时记录目标当时的Order作为**停用恢复点**，与Base Order分开。停用/销毁/换目标时只在目标仍保留本组件最后写入值且层ID未变的情况下恢复；外部后来改Order或层ID时，Status=ExternalChange并停止覆盖，停用也不写回旧值。核清写入者后重新启用会建立新的恢复点并按手配Base重算。一个目标只安排一个排序写入者；组件不改非目标、enabled标记或任何Layer ID。
