## 1. 在哪里配置

- 单个 Sprite：选中目标对象，在 **Sprite Outline 2D** 组件上配置。
- 一组 Sprite：选中最近的共同父对象，在 **Sprite Outline Group 2D** 组件上配置；成员仍各自保留 **Sprite Outline 2D**。
- 正式配置入口是上述两个组件。**Sprite Outline Merge Member 2D** 是合并后端的自动同步/诊断组件，不应作为日常调参入口。
- 默认表：选中 `Assets/Resources/SpriteOutlineDefaults.asset`，在 **Generic > Outline Color** 或角色条目的 **Outline Color** 中配置。这是一次性 Reset/显式迁移的源，不会在每帧或 OnValidate 中反向覆盖已有实例。
- Lab 原点位：`Spaces/OutlineShadowMergeLab/SampleMatrix_Group/Forward_Group/Forward_2`。修复后的场景增量入口为 **Tools > Visual Effects Lab > Apply Forward_2 Independent Outline Fix**；执行前先备份场景、相关 meta 和可能已存在的专用夹具。

组件自带的命令从组件标题行右侧 **⋮**，或右键组件标题打开。**Sprite Outline Group 2D** 的“显式创建缺失成员”“显式同步跟随成员”“显式接线现有合并后端”“重新应用到全部子素材”会改接线或派生状态，只应在已备份、明确知道目标组边界时执行；它们不是日常调色按钮。

## 2. 画面原理与限制

单件 Shader 在同一个 SpriteRenderer 中按“阴影 → 描边 → 原图”合成。组级合并使用共享后端消除同组成员交叠处的内轮廓；成员退出合并后恢复自己的单件描边。

Shader 不扩大 SpriteRenderer 的网格。要看到向外扩展的描边或阴影，图片必须有足够的透明留白，Importer 的 **Mesh Type** 必须为 **Full Rect**。全不透明且贴满画布的图片即使颜色 alpha 和粗细正确，也没有可绘制的外围片元；Tight 网格或留白不足还会裁掉粗描边、偏移阴影和模糊边缘。

## 3. Sprite Outline 2D 参数

| Inspector 字段 | 默认值 | 画面影响与使用建议 |
| --- | --- | --- |
| **Outline Material** | None | 描边/阴影 Shader 材质。为空时不能形成独立效果；应使用项目正式描边材质。 |
| **Outline Color** | RGBA(48,35,31,1) | HDR 颜色拾取器中 RGB/强度决定描边发光颜色，**A 滑条范围 0～1**独立决定描边覆盖率。A=0 时描边不可见，0.5 为半透明，1 为不额外衰减；调 Alpha 不改 Sprite 本体透明度、Thickness 或合并开关。HDR RGB 可高于 1，不要用降低 RGB 强度代替 Alpha。 |
| **Thickness** | 6 | 单位为源图片像素，有效范围 0～32；增大后描边更粗，也更需要透明留白。0 关闭描边本身。 |
| **Shadow Enabled** | 关闭 | 开启后才计算阴影；还需要非零 **Shadow Opacity**。 |
| **Shadow Color** | 黑色 | 阴影颜色；日常透明度只调 **Shadow Opacity**。Shadow Color 内部 alpha 继续用于旧数据/高级传递，Inspector 不另暴露第二个 alpha 滑条，避免双重透明度控制。 |
| **Shadow Offset** | (0,0) | 单位为源图片像素；正 X/Y 向纹理右/上移动，负值反向。 |
| **Shadow Opacity** | 0 | 范围 0～1；越大越明显，0 不显示。 |
| **Shadow Blur** | 0 | 单位为源图片像素，范围 0～32；0 为硬边，增大后更柔和且更容易被画布边界裁切。 |
| **Override Group** | 关闭 | 关闭时使用本地参数；开启且存在最近正式组时，本地 Outline Color（含 Alpha）、Thickness 和阴影参数会被该组的值同步覆盖，Inspector 会明确提示去组上调整。关闭后再填写独立本地值。它只选择参数来源，不决定是否参加合并。 |
| **Merge Outline** | Follow Group | 描边是否进入组级合并。**Force Off** 退出合并并恢复独立描边；**Force On** 强制参与；**Follow Group** 跟随组开关。 |
| **Merge Shadow** | Follow Group | 与描边独立控制阴影是否进入组级合并。 |
| **Default Profile Id** | generic | 默认配置档标识；高级接线项，普通调参不要随意改。 |

容易混淆的两点：

1. **Override Group** 与 **Merge Outline / Merge Shadow** 互不替代。前者决定“用谁的参数”，后者决定“是否合并”。
2. **Merge Outline = Force Off** 不是关描边。要看到独立描边，还必须同时满足材质有效、颜色 A>0、Thickness>0、图片有透明留白且网格为 Full Rect。
3. Alpha 是覆盖率，HDR RGB 是颜色/强度；两者在颜色拾取器中分开调。同一 Alpha 在深色、浅色或高对比背景上的主观明显度会不同，必须在实际背景混合中验收。

## 4. Sprite Outline Group 2D 参数

组的描边材质、颜色、粗细和阴影字段含义与单件相同，默认值也相同。额外字段如下：

| Inspector 字段 | 默认值 | 作用 |
| --- | --- | --- |
| **Include Inactive** | 开启 | 同步时是否包含未激活的成员。 |
| **Direct Children Only** | 关闭 | 开启后只管理直接子对象；关闭时包含后代。嵌套组仍以最近组为所有者。 |
| **Merge Outline** | 开启 | 组级描边合并总开关，供成员 Follow Group 使用。 |
| **Merge Shadow** | 开启 | 组级阴影合并总开关，供成员 Follow Group 使用。 |
| **Default Profile Id** | generic | 组默认配置档标识。 |

组上的值是共享样式，其 **Outline Color** 同样在 HDR 拾取器中显示 0～1 Alpha；成员上的 **Override Group** 决定是否采用并同步覆盖为这套值。组/成员 Inspector 下方的后端、宿主、预算和“实际合并”信息属于接线与诊断，不是另一套视觉参数。

### 4.1 自动同步成员：只读理解与排障

**Sprite Outline Merge Member 2D** 是 `SpriteOutline2D` 向最近正式后端同步的适配器。以下字段正常情况下由正式组件/组维护，不应与正式入口两边手调：

| Inspector 字段 | 代码初始值 | 含义 |
| --- | --- | --- |
| **Source Renderer** | None | 被合并的 `SpriteRenderer`。正式接线后应指向同对象渲染器。 |
| **Merge Outline / Merge Shadow** | Follow Group | 派生后的两项参与请求；应与 **Sprite Outline 2D** 的同名设置一致。 |
| **Use Group Outline Parameters** | 开启 | 描边色宽是否取正式组；对应正式组件的 **Override Group** 语义。 |
| **Outline Color / Outline Thickness In Source Pixels** | 白 / 1 | 退出组参数时保留的本地描边快照。单位仍是源像素。 |
| **Shadow Color / Shadow Offset In Source Pixels** | 黑 / (1,-1) | 独立阴影的颜色和源像素偏移快照。 |
| **Shadow Opacity / Shadow Softness In Source Pixels** | 0.5 / 1 | 独立阴影透明度与柔化半径快照。 |

Member Inspector 显示“最近所有者”和解析后的组开关，用于判断它是否归属了错误的嵌套组。修改正式组件后若派生值没有同步，先查最近启用组/后端、组件生命周期和 Console，不要直接把 Member 改成“看起来一致”。

### 4.2 合并后端：高级接线、预算与运行状态

**Sprite Outline Merge Renderer 2D** 是组级渲染后端，不是第二套配置源：

- **Target Camera**、**Merge Shader**、**Shadow Host / Shadow Host Mesh**、**Outline Host / Outline Host Mesh**、**Members** 是显式接线；缺一项时不能把单件输出安全交给后端。
- **Resolved Group Defaults** 下的组描边/阴影字段由最近正式组同步。若与 **Sprite Outline Group 2D** 不同，应修正式组接线或同步链，不应在后端建立另一套视觉样式。
- **Maximum Texture Size** 默认 4096，最小 64；实际上限取它和 `SystemInfo.maxTextureSize` 的较小值。超过上限时后端会停用输出并报错，不会静默裁一块 RT。只有确认目标硬件、实际 bounds 和显存预算后才提高。
- 每个启用的正式组固定使用两张持久 ARGB32、AA1、无 mip RT，尺寸按成员世界范围、源像素边距和目标相机像素密度计算，再向上对齐到 8。稳定且状态未变时复用缓存，不应逐帧重新写入或分配；禁用/销毁后释放 RT、运行时材质和网格，并恢复宿主原状态。

当前 `Forward_Group` 的组样例为青色 RGBA(0.15,0.9,1,1)、Thickness=2，阴影开启、色 RGBA(0.05,0.03,0.08,1)、Offset=(3,-3)、Opacity=0.55、Blur=2，组描边/阴影均合并，Maximum Texture Size=4096。`Forward_2` 当前本地样例为洋红色、Thickness=4.8、阴影 Offset=(2,-2)、Opacity=0.5、Blur=1、双 Force Off。它们是当前场景样例，不改变组件默认值。

RT 成本会随宽高相乘增长：Lab 的正式大猫样例曾实测 7584×6104×2 张，约 353.19 MiB；P0/P1 迁移前曾测 2008×4168×2 张约 63.85 MiB，AI120 迁移后相邻层初验采样为 2008×3904×2 张约 59.81 MiB。尺寸会随当前成员范围与状态变化，不能把某次采样当固定预算。不要为了消除尺寸报错盲目提高上限，应先检查成员是否误归组、相机像素密度、父级缩放、透明留白和实际需要覆盖的边距。

### 4.3 冰箱猫整组随动合同

- 正式组与 `Sprite Outline Merge Renderer 2D` 继续挂在固定 `FridgeCat_Rig` 根；这两个组件是样式/接线所有者，不需要随滚动移动。
- `FridgeCat_Rig_MergedShadow` 与 `FridgeCat_Rig_MergedOutline` 两个显示宿主必须位于 `VisualContent_TUNE` 内，与 Head、眼、肢体、Tier 等 14 个源成员共同继承一次 `ContentArea_TUNE` 位移。不要把宿主留在固定根，否则会滞留；也不要再给宿主加第二个跟随组件，否则会双倍位移。
- P0 的 Tier_03~06 增加 4 个显式成员，后端成员总数为 18；源 Prefab 仍为 14。增减层时先保证 `FridgeCatRig.extensionTierRoot=Tiers` 和 Binder 显式引用正确，再同步后端成员，不要按名字自动扫整个场景。
- 根组当前 `Include Inactive=开启`、`Direct Children Only=关闭`，因此 `VisualContent_TUNE` 新增中间层不会改变最近正式组归属。两个嵌套 Eye Prefab 保持 Connected，不应为滚动拆包。
- AI120 初验在 P0 tier0→1 记录内容 delta 约 `(0, +1.05631, 0)`，11 个视觉根与两宿主的最大 mismatch `5.75e-6`，低于 `1e-4` 数值初筛容差；合并后端 `Owned RT=2`、`Peak RT=2`、`Last Error` 为空。这只证明单次相邻层机器合同，完整边界/重入和肉眼接缝仍按后续验收执行。

### 4.4 常用组合

- 整组统一外轮廓、不画成员内接缝：组 **Merge Outline=开启**，成员 **Merge Outline=Follow Group**；需要统一样式时成员 **Override Group=开启**。
- 同组仅一个成员保留独立描边：该成员 **Merge Outline=Force Off**；若仍想用组色宽，保持 **Override Group=开启**，若要本地色宽则关闭。
- 只退出合并阴影：保持描边 Follow Group，把 **Merge Shadow=Force Off**。描边和阴影三态彼此独立。
- 关闭某成员描边：把 **Thickness=0** 或颜色 A=0。不要用 Force Off，因为 Force Off 是“独立绘制”，不是“关闭”。
- 软阴影起点：先启用阴影，Opacity 从 0.25～0.5、Blur 从 1～3 源像素、Offset 从小位移开始；确认透明留白后再增加。这里是建议，不是默认值。

### 4.5 ShortCycle Hover 临时覆盖

`ShortCycleOutlineGroupBinding` 的业务 Hover 会临时把目标改为高亮色（当前 Alpha=1）并增加粗细；这不是正式静态配置的第二权威。进入 Hover 前会快照目标当前的完整 HDR RGBA 与 Thickness，退出 Hover、组件禁用时都恢复该快照。AI141 已以 HDR `(1.7,0.3,2.2,0.42)` 实测退出与禁用均精确恢复；因此不要在 Hover 正在生效时把 Inspector 中的临时高亮值误写成默认值。

## 5. Forward_2 当前修复样例

修复入口会在原 `Forward_Group` 上建立一个正式组作为唯一权威源，继续复用原合并后端、两个显示宿主、成员集合和原组样式：

- `Forward_0`、`Forward_1`：使用组参数并按 Follow Group 参加合并。
- `Forward_2`：保留在同组，但 **Override Group=关闭**、**Merge Outline=Force Off**、**Merge Shadow=Force Off**，用本地可见色宽独立绘制。
- 专用夹具：128×128 PNG，中间 64×64 不透明白块，四周各 32 像素透明留白；PPU=64、Pivot=Center、Mesh Type=Full Rect。
- 原 `VfxLabWhite.png`、对象 Transform、Sorting Layer/Order、合并 Shader 和运行时算法不改变。

修复入口是显式且幂等的：不会随脚本重载自动改场景；遇到未知同名图片会拒绝覆盖。AI112第二次实际执行已返回“配置已匹配、无场景重写”，scene、PNG及双方meta的SHA/长度/写入时间均未变化。当前样例色宽由原组件/Adapter 安全继承，不把本文的建议值写成固定视觉保证。

2026-09-15机器复验使用固定Main Camera与768×512 RenderTexture：Follow Group与Force On画面逐像素一致；Force Off只在Forward_2范围产生差异并显示完整独立外轮廓；alpha=0与Thickness=0画面一致，alpha=1及换色均产生明确差异。第二次Play的Force Off图与第一次SHA一致，Stop后10个后端合计RT和运行时材质均归零。截图位于`Captures/AI-000112/`；这些结果证明机器合同，不代替用户对线宽、颜色和整体观感的主观签收。

### 建议起点（不是默认值）

- 一般角色或图标可先从 2～6 源像素描边、颜色 alpha=1 开始，再按实际 PPU 和镜头距离调整。
- 透明边至少覆盖预期的“描边宽度”或“阴影偏移绝对值 + 模糊半径”中的较大值；临界值还应留少量余量。
- 先在 alpha=1、无阴影条件下确认描边，再逐步加入偏移、透明度和模糊，便于区分参数问题与裁切问题。
- 当前 Forward_2 样例沿用本地 4.8 源像素宽，专用夹具提供32像素透明边；这是该样例值，不会改变组件的默认6像素。

## 6. Unity 验收操作

1. 先备份 `VisualEffectsLab.unity`、相关 meta，以及可能已存在的专用夹具；再运行修复菜单。
2. 保存、重载并运行 Outline 专项只读 Audit；确认原几何、排序、组样式和后端引用保持。
3. Play 后在 **Outline Shadow Lab Driver** 使用 **聚焦 Forward_2**。该按钮只在 Play 生效，会保存原 MainCamera 位置、旋转和正交尺寸；验收结束点 **恢复原相机**，组件禁用时也会恢复。
4. 对 `Forward_2` 依次观察 Follow Group、Force On、Force Off；验证 Force Off 时组内交叠处保留独立描边，同时另外两件仍合并。
5. 在不改 Thickness、Merge Outline/Shadow 和 SpriteRenderer 本体颜色的前提下，依次设置 **Outline Color Alpha=0 / 0.5 / 1**；对比独立 Force Off、本地参数合并、Override Group 跟随组三条路径。再在 Alpha 不变时单独提高 HDR RGB 强度，确认“透明度”与“HDR 强度”差异。
6. 分别换成深色、浅色和高对比背景，确认 Alpha=0.5 的背景混合；不得用中间 RT 数值代替最终 Game View/GPU 观察。
7. 检查 Console、Shader 导入、两张合并 RT、Stop 后释放、保存重载 clean；只有真实 Game View/GPU 画面成立后才能签收。

本说明不把静态测试当作视觉验收结果。AI141 已在真实 Play/GPU 中完成单件与组 Alpha=0/0.5/1、HDR>1、明确深色背景混合、主体不受影响、组/本地/三态、Defaults 临时副本保存重载、Hover 恢复和双 RT/Stop 释放；证据见 `Captures/AI-000141/` 与 `.ai-workspace/outputs/OUT/OUT-ALPHA-T2_透明度配置与Lab复验.md`。正常 Inspector 颜色拾取器的可见/可编辑 Alpha 因 Windows 窗口捕获接口失败仍待用户当面确认，最终主观观感也不由机器截图代签。

## 7. 菜谱封面 C 标签实例（AI125）

- Lab 对照入口：`Spaces/RecipeCoverLabelSample_Group/Label_OuterOutline_TUNE`。
- 正式场景入口：`Spaces/Phase0_RecipeBook/Cover_Group/CoverLabel_C_TUNE`。
- 在上述对象的 **Sprite Outline 2D** 上配置：**Outline Material**=`Assets/Materials/2D/SpriteOutline2D.mat`，**Outline Color**=RGBA(48,35,31,255)，**Thickness**=6 源像素，**Shadow Enabled**=关闭，**Override Group**=关闭，**Merge Outline / Merge Shadow**=Force Off。
