# 普通对话界面、立绘与街景反应使用说明

最后局部核对：2026-11-23，实际源码、演出配置保存值、对话Prefab和Street磁盘引用，以及已完成的正式导表/首次原生保存读回。本文面向配置人员；本轮只维护文档，没有运行Unity或修改任何资源。右侧镜像经用户对照原画确认通过，原图朝向由美术交付统一。0.1.5 人工验收进度见项目内人工检查说明。

## 当前对象和接线入口

正式Prefab：`Assets/Prefabs/UI Components/NarrativeDialogueUI.prefab`；正式场景：`Assets/Scenes/LongLoop/LongLoop_Street.unity`。Scene实例继承Prefab舞台和模板，不需要用户重复搭一套界面。

| 哪个对象 / Inspector组件 | 字段 / 默认 | 当前保存与作用 |
| --- | --- | --- |
| HUD根 / Narrative Dialogue Composition | Portrait Stage，None可空 | 接本Prefab Portraits层的Narrative Portrait Stage；无舞台沿无图流程，不为空步骤等待 |
| HUD Portraits / Narrative Portrait Stage | Portrait Template，None | 接直接子节点PortraitTemplate_TUNE的Image；运行克隆它产生自有图，模板本身不显示 |
| HUD Portraits / Narrative Portrait Stage | Mirror Right Portraits，默认true | 当前true。开只镜像解析为右侧的图，关全部正向；左/中不翻。无单位，不在演出资产里 |
| PortraitTemplate_TUNE / GameObject、Image | 启用框 / Source Image / Raycast Target | 当前停用 / None / false；仅RectTransform、CanvasRenderer、Image，不加布局器或另一个驱动 |
| PortraitTemplate_TUNE / Rect Transform | 模板接线值，不是角色取景参数 | 底中Anchor/Pivot=(0.5,0)，位置/尺寸为0，Scale=(1,1,1)；运行尺寸由整图/取景/编排给出 |
| StreetDialogue_TUNE / Narrative Dialogue Service | Presentation Composition | 接同场景HUD根Composition，仍使用同组Box/Dimmer/Stage和操作锁 |
| StreetDialogue_TUNE / Narrative Street Reaction Adapter | Dialogue Service、Target Registry、Street Camera、Player Controller；源码均None | 四项已保存：本场景服务、NarrativeTargetRegistry_TUNE、Cam_Street、PlayerRoot_TUNE上的LongLoop Player Controller |
| NarrativeTargetRegistry_TUNE / Narrative Target Registry | Player，默认None | 当前PlayerRoot_TUNE/Foot_TUNE，作为坐标取样目标；不要改为Visual |
| NarrativeSceneDebugPanel_TUNE / Narrative Scene Debug Panel | Portrait Stage，默认None | 当前接场景HUD继承的同一个Stage；仅Editor/Development使用，发布版本没有F8 |

**Player Controller必须属于Registry脚底的主角根。** Registry可绑定控制器Transform或其脚底；适配器从该目标自身/父链找最近控制器，身份标记只读该控制器同节点Narrative Actor Marker。当前Street保持Foot_TUNE，控制器和标记在所属PlayerRoot_TUNE。显式错主角、缺标记/空ID、跨场景引用会拒绝，不搜索全场景或向其它主角借身份。位置始终取Registry目标，不把控制器根位置替代脚底。

接线属于高级配置：保留已经保存的引用，不为调取景断开组件或改玩家/镜头参数。缺服务/注册表/相机/匹配主角时组件停止反应并给诊断；不会自动猜Camera.main或另一个主角。

## 立绘图片、对准点与站位

完整逐步操作、五图归属、F8抄回和对准示意见[内容配置的立绘章](../../docs/街景NPC内容配置说明.md#portrait-config)。正式图放 `Assets/Sprites/Narrative/Portraits/`，Sprite Mode必须Single整图；Characters.portrait_sprite只填唯一精确基名。运行引用由导表生成，不手填Generated或改旧切片。

图上对准点是 `(0.5+portrait_offset_x, portrait_offset_y)`，按含透明留白的整图宽高比例、从左下计算；它对到Stations/cast给出的屏幕显示锚点。角色表倍率×站位倍率×本段cast倍率，再乘当前说话者高亮。偏移并非移动屏幕锚点；右侧镜像也不改变所选对准点。下半图超出屏幕边缘会正常裁切，不另裁出“人物下半身”资源。

显示锚点以2560×1440底边中心为原点，右/上为正，Canvas按高度缩放。锚点X绝对值小于1参考像素为中间，负为左、正为右。镜像、名字侧和左右滑动使用这个解析侧别，不按高亮或F8横移后重新判断。

一段只解析一次站位/图片；cast为空、全无图或未绑定舞台时，立绘步骤被略过，正文/名字仍可正常工作。无图者不计人数、不留空位；说话者不在名单或旁白时，所有已有图按听众态。不支持在四个cast槽中用列表塞第五人。

## 入场、逐句和退出

全局入口是 `Assets/Settings/Narrative/DialoguePresentationConfig.asset` 的 **Data**。模板/段落overrides在段开始取快照，改值后下一段才重取；配置表、源码默认和当前保存值见[参数说明](../../docs/参数调整说明_对话.md)。

| 分组 / 字段 | 源码默认与当前default保存值 | 配置人员看到的影响 |
| --- | --- | --- |
| Entrance.Order | Sequential，可选Parallel | Sequential压暗→有图时立绘→出框；Parallel同时开、等最长，无图不空等 |
| Entrance.Dim Time / Portrait Time / Box Time | 0.15 / 0.25 / 0.2秒，有限≥0 | 对应阶段时长，增大更慢，0到位；顺序模式会推迟下一阶段 |
| Entrance.Portrait Slide / Portrait Fade | 160参考像素 / true | 左右从本侧外移入，中间不横移；距离0无横移，Fade关只关闭入场淡入 |
| Exit.Order | Sequential，可选Parallel | Sequential收框→有图时立绘退出→回亮；Parallel同时 |
| Exit.Box Time / Portrait Time / Undim Time | 0.15 / 0.2 / 0.2秒，有限≥0 | 对应阶段退出时间，0直接完成；无图略去portrait |
| Exit.Portrait Slide | 160参考像素，有限≥0 | 左右向各自外侧移出并淡出，中间只淡出；0只淡出 |
| Exit.Control Resume | AfterBoxClosed，可选AfterCameraReturned | 前者关框即交还控制，旧图/回亮可在后台继续；后者等待普通段退出全部完成，没有真正回镜头步骤 |

逐句说话者的名字侧、高亮和打字同时开始，不互相等动画。说话者明亮、额外放大/上浮/向内移，并临时在同批前面；换人回基础层次，旁白全体变听众。**最后一句打完后，只要仍在等待下一次推进，当前具名在场说话者就继续高亮；自然出完、点击补全和快进出完都一样，未完成的高亮过渡继续走完。** “可以结束”不等于已经退场，不因此清空说话者或把整批转灰；旁白/名单外仍是原听众态。AUTO 开启时，末句在本段 Auto Wait 到时后自动退场或续接，无需手动确认。下一段按新句说话者更新，不沿用旧批高亮。Speaker六项的单位、零值和默认见参数说明。退出从当时已画的位置/透明度开始，高亮冻结，不先突然回亮或复位。续接时旧批退出、新批进入各自完成，压暗请求各自释放，不因旧图结束关闭新段。

整次中止或组件停用/销毁会清自有图；正常结束播退出并销毁批次，停用无图模板始终保留。每批每角色一个Image，多个批次退出/进入时可短暂共存；未量测GPU/帧率，不保证任意分辨率或大倍率都无遮挡。

## 名字框和作者布局

右侧名字位置由初始化保存的作者Name左侧锚点、轴心和位置镜像得出，**调左侧即可**，不用添加右名字节点或在演出资产找名字X。每段Show先回作者左侧；当句说话者立绘解析为右侧时名字在右，其它情况（左/中/无图/名单外/旁白）回左，空名隐藏。右侧改成长名字时向左增宽，右边距保持；停用恢复作者左侧和初始尺寸。

| 正式作者入口 | 当前保存样例（非终调建议） | 调整与限制 |
| --- | --- | --- |
| HUD根 / Canvas、Canvas Scaler | Overlay，排序200；参考2560×1440，Scale With Screen Size、Match Height=1 | HUD跟屏幕，不跟世界镜头；气泡100、提示150在其下，不与世界Sprite层直接比较数值 |
| Dialogue/Box的RectTransform | 2107×333，底中(0,54) | 改作者Rect调整框位置/尺寸，动画以它为基准；不靠旧自动生成Box Size字段重排作者树 |
| Body TMP / 作者正文布局 | 字59，左右留白93/107、顶部70 | 字号和留白在作者节点，换行/字位需实际TMP人工看 |
| Name TMP / Name RectTransform | 字43，初始最小267×83，左侧偏移(67,45) | 内容可增宽；改作者左侧位置后正常重启初始化，右侧随镜像，不承诺任意长名可放进框 |
| AUTO / 快进的Image和Caption | 133×53，字26；右下AUTO(-440,30)、快进(-267,30) | 保原命中引用和独立文字；按钮状态色由代码切灰/绿，别只改一次Image颜色期待永久替换 |
| HUD根 / Narrative Dialogue Box View | Text Line Height=83参考像素 | 是行距校准入口，必须以真实跨行慢显/补全检查；不是字体已验收保证 |

作者引用必须在同一HUD且完整，保留原Advance Surface与按钮输入通道。运行自动驱动的TMP/RectTransform/CanvasGroup不是保存入口；不要在运行中挪克隆后当配置已经落地。AUTO/快进只切开关，不同时推进句子；面板关闭/窗口外按原交互。设备输入、长名、换行和点击布局仍交人工，不用改速度掩盖字位问题。

## 街景反应与操作锁

**位置保持；朝向在对话开始时转向对方一次，之后保持。** 主角的同一操作锁阻止移动输入；首次面对使用原控制器朝向路径，不移动坐标、不解开锁，后续句子/听众反应不再次命令主角。整次结束/中止不把主角朝向转回开始前。同一轮自动续接不重复首次面对。

NPC沿原Npc Shell、Narrative Actor Marker与Foot接入Registry，无需逐NPC另挂反应组件。首次面对使用实际发起实例；同角色发言优先该实例，其它按精确角色目标查，不猜其它#后缀实例。听众到点按当前Foot视口与near/far范围判断活动NPC，排除说话者/发起者/主角；脚底在屏内与贴图部分可见含义不同。

Reaction默认 **Turn Mode=FaceSpeaker / Turn Delay=0.2秒**。None只关闭听众转身，首次面对仍做；0秒句通知立即处理；正延迟随对白游戏delta暂停。换人替换等待，同人不重计，旁白/找不到目标取消。整次结束、中止或引用失效恢复已转NPC的首次原朝向，续接不恢复。节奏、镜像是否合适和人选请用户观察，不做引擎逐帧/阈值/截图比较。

## F8临时取景

只在Editor/Development、进行中对话有图时按F8看“立绘调参”。偏移X/Y每次±0.01整图比例，角色缩放每次±0.02且>0；同角色的当前/后续批共用覆盖，窗口可滚动。**复制**输出Tab分隔的ID、x、y、scale到剪贴板及Console；按ID手工回填作者工作簿Characters后三列，再正式导出/导入，步骤见内容说明。

**清除全部临时值**清本舞台所有角色覆盖，包括当前不出场者；不清已聊、不写表/存档。关闭面板不保存，清舞台节点不等于清覆盖，实例销毁才消失。检查新表值前先清临时覆盖或正常停止再进入。区内点击由原面板拦截，不推进正文；无舞台隐藏此区，空闲/无图只有说明；Release没有F8。

## 当前边界与检查路径

表情差分、强调、CG、黑边、剧情镜头、背景模糊、反应图标及无缝续接未接当前普通界面；`portraitBottomAlign`不读，Seamless会回完整退入场。Pomegranate-2仅留后续表情素材，不能靠填字符串或复制另一个画布承诺已经支持。

建议先保持当前值，按[本版占位清单](../../docs/demo-0.1.5_占位校对清单.md)核图/角色/文字，再按[五列人工表](../../docs/demo-0.1.5_人工检查说明.md)看取景、名字、遮挡、节奏、转身、F8及原字位/点击。建议只是检查顺序，不自动覆盖任何保存值；出现错图/错人/残图先查绑定和作者配置，正式接线或实现错误交开发处理，不用调极短时间掩盖。
