# 街景纵深缩放：配置与使用

最后实际核对：2026-11-04；范围为 AI426 组件及 AI428 朝向缓存生命周期修复的 `DepthScale`、配置读取、脚底补偿和 Controller/Avatar 实际源码与离线测试。AI426 原初始化/停用顺序缺口的拒验及旧原件保留；当前尚未在正式 Street 挂载，原生三点采样与用户观感仍待 ENGINE/USERa。

`DepthScale` 让主角或 NPC 随脚底的世界 Y 改变显示大小。公式为 `因子 = 1 + (基准线世界Y − 脚底世界Y) × 系数`，再将**已保存的本地缩放**乘以此因子。Y 越低通常越大，Y 越高通常越小；它与 WalkArea、移动速度、地面距离 DEPTH 和绘制排序各自独立。组件可挂空对象做验证，但正式交互物件/前景物件不因此自动参与，仍按设计摆放。

在已有街景玩家 Potato 的 `Visual_TUNE` 对象上添加 **Depth Scale** 组件；让角色移动根及用户父链比例保持原状。任意其它对象也可使用同一组件，组件不查找或依赖玩家控制器。效果只在组件启用且运行时更新，不在 Edit 模式自动改保存值。

| Inspector 入口 | 默认值／单位 | 怎么配置、画面如何变化 |
| --- | --- | --- |
| **Ground Line** | 空；场景 Transform | 指向已有的 `GroundLine_TUNE` 水平基准线。空时读取 `StreetConfigs.Current.GroundLine`；两者都没有则不猜对象，撤回自己可安全恢复的缩放并报 MissingGroundLine。把线向上移会增大同一角色的因子，向下移会减小；最终位置由 USERa 调整。 |
| **Local Config** | 空；DepthScaleConfig 资产 | 空时读取 `StreetConfigs.Current.DepthScale`；填入时采用此资产。通常复用 Binder 的共享资产。若没有资产且没有启用覆盖，则返回基准缩放并报 MissingConfig。 |
| DepthScaleConfig 资产 → **Depth Scale Factor** | 程序初值 0.03；每世界单位 | 上述公式的系数 k。调大使同样纵深差带来更大的尺寸变化，0 表示没有纵深大小变化；负值使前后变化方向相反。不是地面距离的 DEPTH。配置改值或 Current 换绑后更新，不累乘旧帧。 |
| **Local Foot Offset** | (0,0,0)；目标缩放前的本地单位 | 目标 pivot 已在脚底时保持0；否则填写从保存 pivot 指向脚底的偏移。例如本地脚底在 pivot 下1单位，填(0,−1,0)。组件根据保存基准、父变换和本地旋转计算世界脚底，再补偿本对象位置，保持脚底不随缩放漂移。不要把缩放后的视觉中心手工回填成脚底。 |
| **Use Override Factor** | false；开关 | true 明确启用下一项系数；false 才回到覆盖提供者/配置资产。数值0不会被误当作“未启用”。 |
| **Override Factor** | 程序初值0.03；每世界单位 | 此处也是公式的系数 k，**不是最终尺寸倍率**。开关启用时优先于提供者和资产；例如0使因子恒为1。 |
| **Depth Override Provider** | 空；高级 MonoBehaviour 引用 | 预留给实现 `IDepthOverride.TryGetDepthScaleFactor` 的组件。提供者启用且返回true时使用它给出的系数；返回false/停用时回配置。当前没有交付区域覆盖实现，普通配置保持空。优先级为本地覆盖开关 → 有效提供者 → Local Config/Current。 |

示例：k=0.03时，脚底在基准线、线上2u、线下2u处因子分别为1、0.94、1.06。若保存 `localScale=(2,3,1)`，线上2u显示为(1.88,2.82,0.94)；这不是把基准强改成(1,1,1)。派发卡只读记录当前 Visual_TUNE 本地缩放为1，用户外层比例独立保留；当前场景并没有已验收的 DepthScale 配置值。所有0.03/三点数值均为开发预设示例。

公式没有 Y 区间和缩放上下限。结果为0时对象收缩为零，负数时各轴按带符号因子反向；源码保留这些计算结果，不隐式裁剪成正数。非有限系数/世界Y/溢出使 Status=InvalidInput：可安全计算基准时撤回本组件因子；脚底偏移或保存基准本身不可计算时保持现值，待修正配置，不继续写入 NaN。Status/AppliedFactor/FootWorldPosition 是运行探针读回项，不是 Inspector 可调字段。

控制器和 Spine Avatar 的朝向入口在启用 DepthScale 时委托组件，只改变独立的朝向符号，保留当前缩放幅度和公式负号；纯纵向不翻朝向。未启用组件时保持既有朝向路径。停用/销毁时仅恢复仍由组件持有的基准幅度，并保留最近请求的左右朝向；重新启用以当前值重新建立基准。若其它脚本改了本对象缩放，或在非零脚底补偿期间改了本地位置，组件报 ExternalChange 并停止覆盖，停用时也保留未知改动；核清来源后再重新启用。要让非零偏移的视觉持续移动，移动其父根，避免多个脚本同时写视觉的 localPosition。零偏移的独立对象可以直接移动。

AI428 补齐初始化顺序：即使 DepthScale 先把保存 X=2 缩到1.88，控制器/Avatar 后初始化也会读取未乘因子的2，而不是把1.88存成永久朝向幅度。停用或移除组件后翻向采用当前已解除倍率的幅度，后续外部改成7则保留幅度7；停用期间的朝向会供重新启用时使用。零/负纵深因子不会作为基准缓存，也不靠除因子恢复。对象从未使用过DepthScale时，原控制器/Avatar的旧缓存行为保持。这些行为不需要新增Inspector开关，也不要求配置执行顺序。
